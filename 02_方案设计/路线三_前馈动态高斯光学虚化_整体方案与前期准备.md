## 1. 为什么这样定位

### 1.1 现有工作的覆盖范围（检索截至 2026-11-09，并不完整，投稿前需复查）

| 方向 | 代表工作 | 现状 |
|---|---|---|
| 2.5D / 扩散视频虚化 | Any-to-Bokeh、BokehCrafter、VBR、PREX、Generative Refocusing | 多帧聚合、可见性置信度已有先例；每次换焦点都要重新推理 |
| 光场重对焦 | Vid2Bokeh（ECCV 2026） | 静态场景、单图编辑 |
| 静态 3DGS 景深 | DOF-GS、DoF-Gaussian、CoCoGaussian | 逐场景优化，输入为多视角离焦图 |
| 动态 3DGS + 物理光圈 | 4D-GRT（arXiv 2509.10759） | 多视角同步视频，逐场景优化（每场景约 3 小时），用 3DGRT 光线追踪渲染；定位是相机效果数据生成工具 |
| 前馈重建 + 物理景深 | 4D-GRT 附录 G：直接把 MoVieS 的重建结果交给光线追踪 | 未针对虚化训练，只是模块拼接；在 CamVFX-4D 上单目景深 23.48 dB / LPIPS 0.309，多视角为 31.25 / 0.121 |
| **为虚化训练的前馈动态高斯** | — | 未见 |
| **单目视频中"光圈可见、当前帧不可见"内容的显式建模** | — | 未见；4D-GRT 在局限部分把"用扩散先验补弱观测区域"列为下一步，有被抢先的风险 |

### 1.2 本项目已有的证据（第一轮复现，静态场景）

DoF-NeRF R1（真实镜头 f/4 照片作真值）的分区结果中，四种方法的边界区 PSNR 都比焦内区低约 6 dB：CoCoGaussian 27.1 / 33.3，DoF-Gaussian 26.5 / 33.0，BokehMe 组合基线 25.4 / 31.3，DOF-GS 25.0 / 31.5（各方法完成的场景集合不同，只看量级）。来源：[`round1-regional-R1.csv`](../03_实验记录/records/dof-gs-repro-2026-11-05-round1-regional-R1.csv)。

能得出的判断：误差集中在遮挡边界；全图上 2.5D 后处理与各方法自带的景深渲染只差约 1 dB，所以"三维表示天然更好"不能当前提。局限：只有静态场景、f/4、前景/背景两档焦点，也分不清边界误差来自遮挡还是来自深度不准。

## 2. 整体方案

### 2.1 一句话主张（待验证）

从单目全清晰视频出发，**前馈**预测多帧融合的动态高斯，经**可微物理光圈渲染**生成虚化，并用虚化损失端到端训练。设计重点是"光圈能看到、而当前帧看不到"的内容：多帧能取回的部分就取回，取不回的部分用光圈可观测度 O 显式标出，再交给修复网络处理。

### 2.2 方案选择

| | 方案一（主线） | 方案二（上界 / 退路） | 方案三（扩展） |
|---|---|---|---|
| 形式 | 前馈多帧高斯 + 可微光圈渲染 + O 门控修复，端到端虚化训练 | 逐视频优化（MoSca / Shape of Motion）+ O + 补全 | 方案一结果作初始化，再做少步逐视频细化 |
| 定位 | 论文主体 | 实验中的慢速上界；C1 失败时的退路 | 消融或"测试时细化"模式 |

三个方案共用光圈渲染器、O 和评测代码。

### 2.3 流程

```text
目标帧 I_t + 上下文帧 {I_t±2, ±4, ±8, …}（可加长时关键帧）
 ① 重建骨干：MoVieS（代码与权重开源，MIT）。需要带位姿的输入；单次最多 13 帧、长边 518；
    输出场景尺度经过归一化，渲染景深前须对齐到真实尺度
 ② 每像素高斯：位置偏移、尺度、旋转、不透明度、颜色 + 动态概率 m + 来源帧 t_ref
 ③ 融合：静态背景跨全部帧持久保留（不做不透明度衰减）；
         动态前景 v1 只取近邻帧；
         可见性过滤：上下文高斯落在当前帧可见表面前方时剔除（防鬼影）
 ④ 可微光圈渲染：光圈盘上 K 个子相机、离轴投影保持焦平面对齐，渲染后在线性 RGB 中平均；
         焦点场 F(x)、光圈 A 可控 → 虚化图 B、光圈可观测度图 O
 ⑤ O 门控修复：输入 B、O、全清晰帧、CoC 图；O 低处修补，O 高处约束输出接近 B
```

O 的定义：对每个像素，光圈光线中命中"来自其他帧的高斯"（t_ref ≠ t）或命中空洞的比例。可以再加上"被观测帧数"作为置信度。

StreamSplat 使用正交投影，不能直接做光圈采样，因此不作为骨干。

### 2.4 贡献点与对应消融（均为假设）

| 贡献 | 消融（每次只改一个因素） | 主要看的区域 |
|---|---|---|
| C-1 光圈可观测度驱动的前馈多帧融合 | 上下文窗口 无 / 短 / 长；可见性过滤 开 / 关 | 去遮挡带 |
| C-2 为虚化训练的表示 | 端到端虚化损失 开 / 关（对照"先重建再渲染"） | 边界区 |
| C-3 O 门控的物理 + 生成分工 | 修复 无 / 不门控 / 门控；改变光圈时输出是否仍符合物理 | 去遮挡带、全图 |
| 第二贡献：焦点场 F(x) | 定性展示：整体主体对焦、多主体对焦、三维轨迹跟焦 | — |
| 配套：评测协议 | 去遮挡带分区 + 跨帧闪烁 | — |

### 2.5 训练

| 阶段 | 训练对象 | 监督 |
|---|---|---|
| S1 | 高斯头 | 自监督：在上下文视角渲染针孔图，与真实帧比较；深度蒸馏 |
| S2 | 高斯头（端到端） | 多组焦点 / 光圈下的虚化真值（L1 + LPIPS），有子光圈真值时一并加入。优先使用三维正确的真值；若为 2.5D 渲染真值，只在非遮挡区计算损失 |
| S3 | 修复网络 | 虚化真值损失按 O 加权；O 高处约束输出接近 B |

另加时间一致性损失：相邻帧输出经 warp 后保持一致。

### 2.6 实验主线

- **C1**：在 CamVFX-4D 上做，不训练，决定是否继续（见第 4 节）。
- **主表**：ATB、BokehCrafter、MPIB、BokehMe、"MoVieS + 光圈渲染器"（即 4D-GRT 单目方案）、MoSca 逐视频优化（上界）。BokehCrafter、Vid2Bokeh、PREX 视开源情况而定。
- **消融**：见 2.4。
- **真实视频**：DAVIS 和手机实拍，做定性比较与用户研究。
- **效率**：在 4090 D 上统一测量，重点报告"换一次焦点或光圈的边际成本"。

## 4. C1：前提验证（不训练）

按 AGENTS 2.4 说明：

- **要回答的问题**：单目情况下，多帧融合能否明显改善去遮挡带的虚化？误差主要来自重建，还是来自可见性缺失？
- **数据**：CamVFX-4D，每个视角当作一段单目输入（MoVieS 单次 ≤13 帧，按 DyCheck 做法抽帧或分段推理）；景深真值来自数据集。若各视角为固定机位，多帧取回只对运动物体有效，结论范围相应缩小，并另加几段相机运动的自制 Blender 场景。
- **对照**：M2-single、M1、M2 来自**同一次 MoVieS 前向推理**，只改变渲染时纳入哪些高斯，几何完全相同；M0–M3 使用同一个光圈渲染器，深度均先对齐到数据集尺度。

| 编号 | 方法 | 作用 |
|---|---|---|
| M0 | MoVieS 当前帧深度 + BokehMe | 2.5D 基线（几何来源与其余组一致） |
| M2-single | 只用当前帧的高斯 | 单帧三维表示的起点 |
| M1 | MoVieS 原生：所有输入帧的高斯形变到当前时刻 | 4D-GRT 单目方案，直接基线；M1 对 M2-single 看原生多帧聚合的收益 |
| M2 | 本方案融合：静态背景持久保留 + 可见性过滤 + 跨多次推理的长窗口 | M2 对 M1 看融合设计的收益 |
| M3 | 多视角重建或 GT 几何 | 上界 |

- **指标**：全图、边界区、焦内、焦外、去遮挡带的 PSNR / SSIM / LPIPS；跨帧闪烁。
- **判据**（执行前把阈值写进记录）：M2 在去遮挡带上明显优于 M1 与 M2-single，就进入训练阶段。若没有明显优势，先排查可见性过滤、尺度对齐和深度精度，查清前不开始训练。去遮挡带按每组景深参数统计像素占比；占比低于约 1–2% 时，先换更大光圈重新渲染真值再下结论。
- **结论边界**：合成室内场景、512²，景深参数可能比较单一（见 5.1），结论只适用于这一条件。

| 2.5D 真值把错误的遮挡关系教给模型 | 只在非遮挡区计算损失；评测一律用三维真值 |
| CamVFX-4D 景深参数单一或缺深度 | 用点云和位姿或 Blender 补渲染；用多视角重建深度近似去遮挡带 |
| CamVFX-4D 为固定机位，或去遮挡带占比过小 | 结论范围限定为"运动物体造成的遮挡"，另加相机运动的自制 Blender 场景；占比过小时换更大光圈渲染真值 |
| MoVieS 输出尺度归一化、单次 ≤13 帧 | 渲染前用给定位姿或深度对齐尺度；长窗口由我们跨多次推理、用位姿对齐后融合 |
