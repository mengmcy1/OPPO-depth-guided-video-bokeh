# Any-to-Bokeh 改进候选方案：几何可靠性与高效时序推理

> 状态：研究构思与实验规划，待确认  
> 日期：2026-10-14  
> 核心 Baseline：Any-to-Bokeh（ATB）  
> 研究定位：基于预训练视频扩散模型，探索深度先验错误下的鲁棒视频虚化，以及长视频的高效连续生成。  
> **本文件不代表 Ours 已确定或候选改进已验证。**

---

## 1. 研究背景与总体目标

### 1.1 现有 ATB 的技术基础

Any-to-Bokeh 利用预训练 Stable Video Diffusion（SVD）的视频生成先验，结合焦平面自适应多平面图像（MPI）表示和单步扩散，实现具有明确焦点、虚化强度控制的视频 Bokeh 渲染。

其主要输入和条件包括：

- RGB 视频；
- 外部估计的深度/视差信息；
- 焦平面；
- 虚化强度 K；
- 根据几何信息构造的 MPI mask 和相对视差条件。

因此，ATB 已经属于“预训练视频生成大模型 + 几何/光学条件控制”的技术路线。

本项目不需要重新引入大模型作为创新本身，而应研究：

**现有生成大模型在几何输入不可靠、复杂时序变化以及长视频推理时，仍然存在哪些可验证的问题？**

### 1.2 两个主要研究问题

**RQ1：几何可靠性问题**

当输入视差出现结构缺失、边界误判或跨帧不一致时，能否利用置信度、跨帧信息和生成先验，减少错误虚化，同时保留正常区域的质量？

**RQ2：长视频推理问题**

能否减少 WOIS（Weighted Overlap Inference Strategy，加权重叠推理策略）带来的重复计算，在不明显损害视频画质、时序连续性和对焦控制的前提下，提高长视频处理效率？

两个问题暂时独立研究。只有证明二者存在共同机制或互补收益后，才考虑组合。

## 2. 当前基础、已有证据和待验证问题

### 2.1 已经完成的工作

| 内容 | 当前状态 |
|---|---|
| Synthetic 200 段、七方法质量评价 | 已完成并冻结 |
| DAVIS 50 段、六方法评价 | 已完成并冻结 |
| Table 3A 模型计算成本 | 已完成 |
| Table 3B 完整视频推理效率 | 已完成 |
| ATB 模块级时间与显存分析 | 已完成 |
| Encoder scale=1 冗余除法优化 | 已完成四片段验证 |
| 双线失败分析 CPU 探索 | 已完成 |
| B1 人工视觉复核 | 进行中 |
| B2 方法对照与来源隔离复核 | 尚未开始 |
| 最终 Ours 方案 | 尚未确定 |

现有效率研究发现，ATB 的 VAE 相关阶段占带插桩 Core 时间约 80.36%。第一项实现级优化在四个固定片段上验证了输出逐位一致，PyTorch allocated 峰值降低约 4.50 GiB、Core 时间降低约 1.10%。

这些结果保留为实现效率研究，不自动成为本轮新算法创新。

### 2.2 与几何错误相关的论文证据

ATB 的早期论文版本展示了视差结构缺失导致局部错误虚化的案例。正式方法已经通过视差扰动训练和时序模块增强鲁棒性，但这不等于能够处理所有严重结构错误。

需要区分：

- 已有方法可以容忍的轻微边界扰动；
- 输入中整个细结构或局部物体缺失；
- 相邻帧之间的深度预测不一致；
- 生成模型使用了不正确的几何条件；
- 输出异常实际上由焦点选择、场景构造或其他因素造成。

目前不能将这些问题都归因于深度估计器。

### 2.3 与长视频相关的论文证据

ATB 使用 WOIS 处理长视频：将输入分为相互重叠的固定窗口，并对重叠区域进行加权融合，以缓解窗口拼接处的时序不连续。

作者的消融实验表明 WOIS 对视频质量有益。

但重复处理窗口也意味着额外计算。原生 25 帧复现的执行记录为：

| 模块 | 输入帧槽 | 重复真实帧访问 | Padding |
|---|---:|---:|---:|
| CLIP | 48 | 20 | 3 |
| RGB VAE encode | 48 | 20 | 3 |
| CoC VAE encode | 48 | 20 | 3 |
| VAE decode | 32 | 4 | 3 |

这些数字证明存在重复帧槽处理，**不等于已经证明对应特征可以直接复用，也不能直接换算为可节省的运行时间**。

## 3. 方向 A：深度先验错误下的可靠虚化

### 3.1 核心问题

当前 ATB 依赖外部几何估计。如果视差错误进入 MPI 条件构建，可能影响焦点区域判断和虚化生成。

尤其值得研究的情况包括：

1. 细结构在视差图中缺失；
2. 同一主体被错误分配到不同深度；
3. 前景和背景的深度边界偏移；
4. 相邻帧中相同物体的深度预测不稳定；
5. 错误视差在较大 K 下产生更明显的虚化偏差。

但这些只是优先检查的条件，不能直接当作 ATB 已证实的失败类型。

### 3.2 候选 A1：替换或修正上游深度估计

基本流程：

```text
RGB 视频
    ↓
候选深度估计器 / 深度修正
    ↓
统一视差标定、归一化与焦点控制
    ↓
冻结 ATB
    ↓
虚化视频
```

主要目的：判断改进输入几何，能否在不修改 ATB 权重的情况下改善虚化。

**第一步不建议从零训练新的深度基础模型。**

先采用已有估计器、可控几何修正或合成几何真值作诊断对照。

重要限制：

- 更好的通用深度指标不一定意味着更好的 Bokeh；
- 不同深度模型的相对尺度和偏移可能不同；
- 改变深度归一化或焦点值也可能改变实际虚化强度；
- 需要区分几何质量改善与焦平面/CoC 标定变化。

如果简单更换深度模型就能改善结果，这是有价值的诊断证据，但尚不足以构成独立算法创新。

### 3.3 候选 A2：深度可靠性估计与任务感知修正

提出一个候选的深度可靠性图：

\[
C_t(x,y)\in[0,1]
\]

表示当前视差在像素位置 \((x,y)\) 的可靠程度。

可靠性线索可考虑：

- RGB 图像中的结构和边缘；
- 当前深度图中的不连续性；
- 相邻帧几何对应关系；
- 不同深度预测之间的分歧；
- 焦平面距离和虚化强度；
- 估计器自身能够提供的不确定性信息。

需要注意：图像边缘复杂、深度变化大，不必然意味着深度错误。可靠性不能简单等同于梯度强度。

一种候选修正形式为：

\[
D_t^{refined}
=
C_tD_t^{pred}
+
(1-C_t)D_t^{repair}
\]

其中 \(D_t^{repair}\) 是额外修正机制产生的深度。

这仅是初步结构示意。如何估计、校准 \(C_t\)，以及怎样获得可靠的 \(D_t^{repair}\)，仍是研究问题。

### 3.4 候选 A3：失焦感知的深度可靠性

ATB 的虚化半径关系为：

\[
r=K|d-d_f|
\]

因此，深度误差对最终虚化的影响还与 K、焦平面有关。

拟研究：

**能否直接预测某个几何错误对最终 Bokeh 结果的风险，而不是只预测通用深度误差？**

例如：

- 某些背景内部的小深度偏差可能不明显；
- 对焦主体附近的深度错误可能导致明显失焦；
- 同样幅度的几何误差，在不同 K 下可能产生不同影响。

候选方法可以利用预训练视觉特征、几何时序信息和焦点条件，学习任务相关的风险表示。

下一步需要比较：

1. 不使用置信度；
2. 只使用普通深度置信度；
3. 使用焦点/K 感知的置信度；
4. 在置信度基础上增加几何修正或条件控制。

**核心要求：不能只是新增一张置信度图，必须证明它能够可靠识别风险，并帮助改善结果。**

### 3.5 候选 A4：将可靠性注入 ATB 的生成条件

若前面的输入级修正有效，可以进一步考虑：

```text
RGB 视频 ───────────────┐
                        │
原始视差 ──┐            │
           ├→ 可靠性与修正 → MPI 条件
焦点/K ────┘            │
                        ↓
                 预训练视频扩散模型
                        ↓
                    Bokeh 视频
```

可以研究的接口：

- 只修正输入视差，冻结 ATB；
- 将可靠性用于 MPI mask 或视差条件构建；
- 将可靠性引入条件注意力或轻量 adapter；
- 仅在风险区域进行修正，其他区域保持原生路径。

这些改动应逐个验证，不能一次全部加入。

**这条线潜在的创新重点是：让生成模型能够区分可信与不可信的几何条件，并有依据地选择修正方式。**

## 4. 方向 B：高效 WOIS 与跨窗口时序建模

### 4.1 核心问题

WOIS 通过重叠窗口和融合减轻长视频拼接问题，但同时引入重复计算。

这里有两个不同目标：

- **效率目标**：减少重复运算，保持输出质量；
- **时序目标**：改进跨窗口连续性，降低明显的接缝、焦点或纹理变化。

目前已经有重复计算证据，但尚未证明当前冻结 ATB 在窗口边界存在系统性视觉失败。

### 4.2 候选 B1：重复特征复用

基本思路：

```text
窗口 A：计算特征 ─────┐
                      ├→ 对安全、等价的部分复用
窗口 B：读取可复用特征 ┘
                      ↓
              原有视频生成与融合
```

优先检查：

- 输入预处理是否可以复用；
- CLIP 特征是否依赖窗口上下文；
- RGB VAE 编码结果是否受到采样与缓存状态影响；
- CoC 条件是否相同；
- 时序 UNet 的隐藏特征是否依赖整个窗口；
- 解码阶段的缓存与窗口接续是否允许复用。

**不能直接把所有相同帧的特征当成可复用特征。**

对于依赖随机采样、时序上下文或缓存生命周期的部分，需要特别谨慎。

第一轮研究目标仅是确定：

> 哪些中间结果可以在两个窗口之间共享，而不改变冻结推理的语义？

若可以严格保持等价，再测时间、内存与缓存成本。

### 4.3 候选 B2：自适应重叠与融合

原生 WOIS 使用固定窗口和重叠长度。可以研究是否根据视频特征分配不同的重叠程度。

候选信息包括：

- 运动强度；
- 遮挡变化；
- 相邻帧特征差异；
- 几何稳定性；
- 窗口边界的预测不一致程度。

可能的研究形式：

- 场景稳定时减少重叠；
- 场景变化复杂时保留较大重叠；
- 根据局部可信程度调整融合权重。

注意，运动大并不必然意味着需要更多重叠；改变窗口还可能影响输入上下文、随机流和生成结果。

所以必须建立 **效率—视觉质量—时序稳定性** 三者的受控对照，而不预设动态窗口必然优于固定 WOIS。

### 4.4 候选 B3：跨窗口记忆与信息传递

相比仅在输出 RGB 层融合，进一步考虑在生成过程中传递跨窗口信息。

可能的共享对象包括：

- 稳定的几何表示；
- 上一窗口的可信背景/遮挡信息；
- 经过筛选的时序特征；
- 与目标焦点有关的历史条件。

其潜在意义是减少相邻窗口相互独立生成带来的冗余与不连续。

但这是更高风险的路线：

- 隐藏特征可能依赖窗口位置；
- 旧信息可能不适用于新的遮挡状态；
- 错误几何可能在长序列中传播；
- 需要考虑长期运行的内存开销；
- 可能需要轻量微调甚至重新训练部分时序模块。

只有固定 WOIS 确实存在难以解决的效率或时序问题时，才值得推进此方案。

## 5. 两个方向是否应该结合？

可以考虑，但不预设必须融合。

一个潜在的统一研究问题是：

**视频生成模型能否根据时空几何信息的可靠程度，自适应决定如何使用当前条件和历史信息？**

例如：

```text
深度估计 ─→ 几何可靠性 ─────┐
                            │
相邻窗口 ─→ 历史场景信息 ───┼→ 条件控制/时序推理
                            │
焦点、K ───────────────────┘
                                  ↓
                         视频扩散生成
```

可能的联系：

- 深度不可靠时，参考其他帧中的可信结构；
- 历史结构不可靠时，减少错误信息传播；
- 时序变化剧烈时，调整历史信息的使用方式；
- 将几何风险作为是否增加时序处理开销的辅助条件。

但这里不应先构建大型统一网络。

需要先验证 A 和 B 各自有效，再判断组合后是否有额外收益。若二者分别解决不同问题，也允许最终只选择一条作为 Ours。

## 6. 验证路线与评价协议

### 6.1 阶段一：完成失败证据汇总

继续已经冻结的 A/B 双线失败分析：

- A 线：数值、区域与时序诊断；
- B 线：人工观看、瑕疵定位、正常场景对照；
- 交叉汇总两条线；
- 固定问题定义后进行来源隔离复核。

重点检查几何输入与虚化异常之间的对应关系，以及窗口交界区域是否有重复可见的异常。

现有 B1 初步观察包括 `repro_190`、`soccerball`、`paragliding-launch`，但均未完成原因确认，不作为已成立的失败模式。

### 6.2 阶段二：最小因果实验

**几何路线：**

- 选取已确认的异常区域和匹配正常对照；
- 固定 ATB、K、随机流和其他生成条件；
- 单独改变输入几何；
- 先进行 oracle/受控修正和估计器替换对照；
- 观察错误虚化能否改善，及其他区域是否退化。

**WOIS 路线：**

- 保留原生 8 帧窗口、4 帧重叠作为基线；
- 先验证可能复用的特征是否等价；
- 单独测试复用、重叠量或融合策略；
- 比较相同输出帧数下的实际 Core、E2E、峰值显存与时序质量。

仅在小规模诊断有意义时扩大实验。

### 6.3 阶段三：候选方法消融

如果某条路线获得积极证据，再考虑训练相应模块，并设计必要消融。

几何路线建议至少区分：

- 原始 VDA + ATB；
- 更换/修正几何 + 冻结 ATB；
- 可靠性估计 + 几何修正；
- 任务相关可靠性/条件控制。

WOIS 路线建议至少区分：

- 原生固定 WOIS；
- 安全特征复用；
- 改变重叠或融合策略；
- 跨窗口状态传递（仅在确有必要时）。

不允许通过同时改变深度、焦点、K、随机流和窗口策略获得无法归因的改善。

### 6.4 评价指标

| 研究目标 | 核心指标与证据 |
|---|---|
| Synthetic 质量 | PSNR、SSIM、LPIPS、区域 MAE/MSE |
| 视频时间一致性 | FD、RM24、指定区域的时序变化分析、实际视频观察 |
| DAVIS 真实观感 | VEPI、原始 PNG/MP4、人工视觉复核 |
| 深度可靠性 | 具有几何参考时的误差定位、风险排序、可靠性校准与误报/漏报 |
| WOIS 效率 | Core、E2E、峰值显存、实际处理帧数和调用次数 |
| 实际可感知质量 | 正常播放观察、局部缺陷定位、同场景方法对照 |

注意：

- Synthetic 的参考是 MPIB-public proxy GT，不等同真实镜头光学真值。
- DAVIS 没有 paired Bokeh GT。
- 不把 FVD 的集合级值当作逐片段排名指标。
- 不把未做运动补偿的相邻帧差分直接称为闪烁。
- 同来源派生片段不能当作独立复现。
- 提升深度指标不必然意味着虚化质量提升。

## 7. 决策标准与阶段安排

### 7.1 什么情况下优先方向 A？

当多个不同来源片段满足以下条件时，优先研究几何可靠性：

1. 人眼能够确认存在异常虚化；
2. 异常位置与可观察的几何输入问题对应；
3. 排除了明显的焦点、渲染参考或显示问题；
4. 只改善几何输入，就能稳定改善异常；
5. 具有正常对照与反例。

### 7.2 什么情况下优先方向 B？

当实验确认以下至少一种情况时，优先研究 WOIS：

1. 存在可以安全复用、且计算占比足够大的重复特征；
2. 减少重叠能够明显降低时间，同时不引入不可接受的质量下降；
3. 跨窗口确实出现可重复的视觉不连续；
4. 新的时序机制比简单调整融合权重具有可验证的优势。

### 7.3 什么时候考虑组合？

只有在独立实验发现几何可靠性与跨窗口信息使用存在明确关联，并且组合优于两个单独方法时，再考虑统一设计。

否则保留独立路线，不强求多模块系统。

### 7.4 当前唯一执行主线

**近期：** 完成 B1/B2 视觉复核与指标交叉汇总，建立已确认的失败场景和正常对照。

**之后：** 选择一个最明确的问题，进行最小因果验证。

**再之后：** 依据验证结果确定主要创新方向、所需模块、训练方式与正式消融。

当前不恢复 16→8 编码微批量、不修改原冻结 baseline、不自动启动 WOIS 或深度模型实验。

## 8. 研究风险与创新边界

1. ATB 已经采用视差扰动训练提升鲁棒性，不能仅以“抗深度噪声”作为新颖性。
2. ATB 已经采用 WOIS 改善跨窗口连续性，不能仅以“使用重叠融合”作为新颖性。
3. 单纯替换 VDA 或增加缓存，可能是工程改进而非独立方法贡献。
4. 置信度不等于正确性；高置信错误和低置信正确都需要检查。
5. 几何更准确，不一定导致最终 Bokeh 更自然。
6. 更短窗口和更少重叠，可能损伤视频生成质量。
7. 当前 25 帧评估不足以单独支撑长视频稳定性声明；后续若研究长期时序问题，需要独立扩展对应测试。
8. 若实验未能证实深度或 WOIS 是视觉异常原因，应允许放弃相应假设。

**本项目首先要得到一个被证据支持的研究问题，然后才是设计网络结构。**

## 10. 当前结论

本项目的潜在创新方向暂时归纳为两条：

**方向 A：几何可靠性感知的视频虚化**

重点是识别并修正对 Bokeh 生成有影响的几何错误，使预训练视频生成模型能够更可靠地利用输入条件。

**方向 B：高效且连续的长视频虚化推理**

重点是减少重叠窗口中的冗余计算，或通过更合理的跨窗口信息利用机制，在效率与时序质量之间取得更好的平衡。

两条路线都有研究价值，也可能存在联系，但目前没有充分的实验依据决定最终 Ours。

**下一步继续已开展的失败分析；完成视觉与数值证据汇总后，再决定第一项真正的算法实验。**
