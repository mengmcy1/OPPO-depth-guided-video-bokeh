## 1. 设定与目标

- **输入**：单目、全清晰 RGB 视频。不使用深度传感器、双摄或其他额外深度输入；深度与遮挡边界几何由方法自己估计。位姿第一阶段沿用 E1 给定位姿，最终系统至少在估计位姿下评价一次（见第 10 节）。
- **输出**：可连续调焦、可调光圈的视频虚化，由 K=64 物理子光圈渲染生成。
- **核心目标**：场景表示既能在中心视角（零光圈）复现输入，又能在每条子光圈光线下给出正确的遮挡变化——该被挡住的被挡住，该显露的背景以真实观测内容显露。
- **一句话**：可见层诚实地表达"当前真正看见了什么、它在哪里、占了像素多少"；隐藏层用视频中有证据的观测回答"光圈打开后还能看见什么"；两者在同一几何坐标和同一可见性规则下合成。

## 3. 系统总体结构

```
单目 RGB 视频 I_{1:T}
  │
  ├─ 几何前端（冻结）
  │     位姿 P_t：第一阶段 E1 给定；之后估计位姿
  │     深度先验 {D_t^k, c_t^k}：SHARP 校准深度、DepthSplat、静止区多帧三角化（各带可信度）
  │     运动掩码 m_t^dyn：沿用 src/c1_regions.py 的 background_and_motion
  │
  ├─ 第一遍：理解场景
  │     ① 用前端几何建立初步观测记忆 M^0（只存经多帧验证的真实观测）
  │     ② 可见层网络 V（第 4 节）逐帧输出可见表面：G_t^vis 与几何锚点（μ₂、b、α）
  │     ③ 用 V 的几何重新融合观测记忆，得到 M^1，并在片段内冻结
  │     ③′ 边界背景：对候选边界像素，Query 按零光圈视线从 M^1 查询正后方背景（与光圈无关），
  │        据此确定拆分决定 b，与边界背景高斯一起缓存
  │
  ├─ 第二遍：按焦点 / 光圈生成虚化
  │     ④ 按焦点 d_f、光圈 A 与 V 的几何确定环带查询区域（边界像素已在第一遍完成）
  │     ⑤ Hidden Query 从 M^1 选择、修正、上色，输出环带背景高斯；与 ③′ 的边界背景合为 G_t^hid
  │     ⑥ 统一合成：足迹次序规则（第 6 节），可选兜底（第 6.3 节）
  │     ⑦ K64 子光圈渲染 → 虚化帧
  │
  └─ 输出：可连续调焦的虚化视频
```

设计原则：

1. **背景只有一个来源。** 任何位于可见面之后的内容——完全遮挡的环带像素和部分遮挡的边界像素——都由 Hidden Query 从观测记忆给出。可见层不放背景高斯，避免重演附十至附十二"两套高斯抢同一空间"的问题。
2. **几何统一。** 可见层修正几何后，记忆、候选与放置标签都在修正后的坐标中重算（第一遍 ③），两遍之间不无限迭代。
3. **长期记忆只存真实观测。** Query 的预测只进短期缓存，不回写长期记忆；可见层的 G1 经多帧验证后才可写入（沿用方案 2.3.1）。
4. **可见层与光圈无关。** 焦点与光圈只作用于环带查询区域与渲染，可见层每帧只算一次，便于时序稳定与缓存复用。边界拆分决定 b 与边界背景在第一遍确定后固定，第二遍不改变；否则同一条边缘会随光圈在“拆分 / 不拆分”之间跳变，推焦时闪烁。

## 4. 可见层网络（暂名 OVG-Net）

### 4.1 表示：每个像素输出什么

每个像素 p 输出一颗**主表面高斯 G1**，外加只作几何锚点、不渲染的若干量：

| 输出 | 含义 | 约束 |
|---|---|---|
| μ₁(p) | 可见表面沿像素射线的深度 | 高斯中心 = 相机中心 + μ₁ · 射线方向，只有 1 个自由度，不能横向漂移 |
| n(p) | 表面法向 | 决定面片朝向 |
| s₁, s₂(p) | 切平面内两个尺度 | 法向方向尺度固定为很小，做成扁平面元（参照 2DGS 的 surfel） |
| α̂(p) | 前景在该像素的覆盖率（几何覆盖率），同时作为双峰深度损失的混合权重 | 内部像素为 1；不再单独预测混合权重 π（对不透明物体 π 与 α 是同一个量） |
| F̂(p) | 纯前景颜色（线性 RGB） | 内部像素严格等于输入 I(p)；只在边界生效 |
| b(p) | 拆分决定（第一遍确定，见下方解码规则） | 不单独监督，由 α̂、前后两峰深度差与第一遍背景可信度共同决定 |
| μ₂(p) | 背景深度候选（不保证真实存在第二表面） | 只作为传给 Query 的背景几何锚点，可见层不在 μ₂ 处放高斯；只在有可靠前后两层标签的像素监督 |
| c(p) | 几何可信度 | 供记忆融合与 Query 使用 |

解码规则：

```
第一遍（与焦点、光圈无关）：
  候选边界：α̂(p) < 1 − ε 且 μ₂(p) ≥ 1.03 · μ₁(p)
  对候选边界像素，Query 以 μ₂ 为中心从冻结记忆 M^1 查询该像素正后方的背景（零光圈视线），得到背景高斯与可信度
  拆分决定：b(p) = 1 当且仅当 候选边界 且 背景可信度 ≥ q_min；b 与边界背景高斯一起缓存
对每个像素 p：
  若 b(p) = 0（内部，或候选边界但第一遍没有可靠背景）：
      G1：位置 μ₁，颜色 I(p)，不透明度 1，朝向 n，尺度 (s₁, s₂)（等同第一版显式层）
  若 b(p) = 1（边界）：
      G1：位置 μ₁，颜色 F̂(p)，不透明度 o(p)，朝向 n，尺度 (s₁, s₂)
      背景由第一遍缓存的边界背景高斯提供
第二遍只为环带像素按焦点与光圈查询，不改变 G1 与 b。
```

**α̂ 与不透明度的关系。** 二维覆盖率不能直接当作单颗高斯的不透明度：像素覆盖同时取决于不透明度、足迹大小和相邻高斯的重叠。不推导解析映射，而用渲染一致性约束：零光圈下，可见层在截断深度 z_cut(p)（μ₁ 与 μ₂ 在逆深度上的中点）之前的累计覆盖应等于 α̂（L_cov，见第 7 节），让网络学会 o 与 (s₁, s₂) 的组合。只统计截断深度之前的部分，即只算前景这一层，不受其他 G1 重叠的影响；这同时约束足迹，减少缝隙。L_cov 只是自洽约束，α̂ 的真实性由外部监督 L_α 保证。

**为什么这样分工。**【判断】把 I 拆成 F 与 B 在代数上欠定：B 未知时 3 个方程、7 个未知数；B 已知也还有 3 个方程、4 个未知数。可见层自己猜 B 就是在幻觉被遮挡内容，正是 SHARP 的老问题。所以可见层只回答它看得见的部分（边界在哪、前景占多少、背景大约多深），背景颜色由有证据的记忆通过 Query 回答。

### 4.2 输入

| 输入 | 维度 | 说明 |
|---|---|---|
| 当前帧 I_t | H × W × 3 | 线性 RGB |
| 相邻帧 | N × H × W × 3，N = 2–4 | 附位姿与内参 |
| 深度先验 {D^k, c^k} | K × H × W × 2 | SHARP 校准深度、DepthSplat、静止区三角化，各带可信度；缺失处可信度为 0 |
| 运动掩码 m^dyn | H × W | 运动区不参与多视角修正 |
| 记忆背景 B_mem（阶段 2 起） | H × W × 3，附可信度与有效掩码 | 来自 M^0 在当前帧的投影；只作为边界拆分的辅助输入 |

光圈与焦点**不**作为输入（原则 4）。

### 4.3 网络结构

```
I_t ──► 冻结 ViT 编码器（DINOv2 或 DA 系列）→ H/14 × W/14 × C      语义与全局几何
I_t ──► 轻量 CNN 高分辨率分支              → H/2 × W/2, H/4 × W/4    边缘细节
{D^k, c^k}, m^dyn, (B_mem) ──► 小卷积编码  → H/4 × W/4
        └──► DPT 式解码器逐级融合          → H × W × 64（逐像素特征 φ）

先验选择（2026-11-18 修正）：网络逐像素预测各先验的选择权重 w^k（softmax，缺失先验权重为 0），
   基础逆深度 = Σ_k w^k / D^k，再加残差；"直接采用最好的先验"是容易学到的解。
   不再使用固定的按可信度加权平均——它在深度断层处混合前景与背景，制造中间深度。

局部多视角修正（只在 m_ref = 低可信区域 ∪ 深度断层附近 ∖ 运动区）：
   以基础深度为中心、按可信度取 S = 8 个逆深度假设
   → 相邻帧特征按位姿投影到每个假设 → 与 φ 做相关 → 稀疏代价 |m_ref| × S
   → 软最大加权 → 逆深度修正量 Δ(1/z)

输出头（作用于 φ 与代价特征）：
   几何头：μ₁、μ₂、n、c
   覆盖头：α̂（阶段 1 起，兼作双峰混合权重）
   外观头：F̂（阶段 2 启用）
   （b 不是网络输出，由第一遍规则得出）
   足迹头：s₁、s₂、o
```

【判断】只在局部做多视角匹配，不建完整代价体：DepthSplat 已给出全局多视角几何，网络只需修正最常出错的位置（前景边缘、低可信区域），算力也省很多。【假设】参数量在数百万量级（ViT 冻结），需实测。

| | 第一版显式层（D0 / D1） | 第二版 OVG-Net |
|---|---|---|
| 是否训练 | 不训练，规则生成 | 训练 |
| 位置 | 单一估计深度，固定 | 多先验融合 + 局部多视角修正，只沿射线 |

## 5. Hidden Query 的改动

第一版 Query（约 3.8 万参数，候选选择 → 几何修正 → 重投影 → 外观融合）保留，改动如下：

1. **查询分两类，由同一个 Query 负责**：边界像素在第一遍按零光圈视线查询（与光圈无关，结果缓存，并决定拆分 b）；环带像素在第二遍按焦点与光圈查询。
2. **新增输入特征**：可见层的 μ₁、μ₂、α̂ 与 c。部分遮挡像素上，μ₂ 作为背景深度假设的中心。
3. **在修正后的几何上重新生成候选**：可见层几何更新后，记忆重新融合（第一遍 ③），候选与放置标签按新几何重算。【假设】正确候选覆盖（目前 GT 可恢复区约 35%）会随可见层几何变准而上升。
4. **边界像素的合成要求**：零光圈下应满足 I ≈ α̂·F̂ + (1 − α̂)·C_hid，其中 C_hid 为 Query 在该像素背景处的渲染贡献（由 L_zero 约束，不另设硬规则）。
5. **激活的类别平衡**：附十三 R3 显示类别平衡加权会把误激活从 41.5% 提到 63.7%、漏激活从 53.7% 降到 35.1%；第二版继续作为消融，不预先固定。

## 6. 合成与渲染

### 6.1 次序规则：从中心像素改为足迹

第一版 O1 只检查隐藏高斯中心投影像素的可见深度 z_v（深度 < 1.03 z_v 则推到 1.03 z_v）。附十三 R3 的零光圈泄漏（E-9）说明，高斯足迹覆盖到相邻像素时，可能在前景边缘处位于相邻背景像素之前。第二版规则：

```
对每颗隐藏高斯 h（中心深度 z_h，中心视角 3σ 足迹 Ω_h）：
  1. 若 z_h < 1.03 · z_v(中心像素)：按 O1 推到 1.03 · z_v（不变）
  2. 足迹检查：若存在 p ∈ Ω_h 使 z_v(p) · 1.03 > z_h（h 在 p 的可见面之前），
     先缩小 h 的切平面尺度，使 Ω_h 只覆盖 z_v(p) · 1.03 ≤ z_h 的像素；
     缩到最小足迹仍不满足的，丢弃 h（不作放置标签）
```

训练标签与预测后处理使用同一规则。阶段 0 先实现并统计各步数量（见第 8 节）。

【假设】前景边缘后的隐藏背景常与相邻的可见背景共面，足迹伸到这些像素时会被缩小或丢弃，可能在子光圈视角下的前景轮廓处留下细缝。阶段 0 另统计被丢弃的真实背景放置标签比例，以及轮廓附近隐藏层在子光圈光线上的覆盖率相对中心像素版 O1 的变化。

### 6.2 零光圈要求

零光圈一律用可见层 + 隐藏层的合成结果与输入 I 比较。边界拆分后（阶段 2 起），边界像素的 (1 − α̂) 由隐藏层补足，只渲染可见层时边界处必然缺背景。因此：

- 阶段 1 全部像素按 b = 0 渲染，下面两条直接按全图统计，并作为训练监控项，低于各自下限时在汇报中标明：①**仅可见层零光圈 ≥ 50 dB**；②**加入隐藏层（含 F2 兜底）零光圈 ≥ 60 dB**（1b 漏报了第①条，第②条实测 38.99 dB）。
- 隐藏层不泄漏的护栏（2026-11-18 修正）：只渲染可见层的零光圈接近完美（约 100 dB），以它为参照的"下降 ≤ 0.1 dB"任何隐藏层都无法满足，不再使用。改为：**候选规则之间直接比较，取零光圈更高者**；另加绝对下限——加入隐藏层后零光圈 ≥ 60 dB（A 约 56–67 dB）；可见层自身零光圈 ≥ 50 dB 的辅助要求不变。以上只在内部像素（b = 0）上统计；相对 A 的 0.1 dB 下降仍照原口径单独报告；
- 边界像素（b = 1）要求合成结果相对不拆分的版本不下降。

### 6.3 兜底

第一版 F2（显式层与隐藏层都未覆盖的光线，取 A 在同一子光圈光线上的渲染）保留为可选兜底：它在估计几何下有效（附十三 T1：D0 与 A 在可恢复区基本持平），但它本身是单图模型的猜测。第二版评价同时报告"有 / 无 F2"，论文主结果是否使用 F2 由消融决定。

### 6.4 渲染器

K=64 子光圈渲染器不变。高斯数量从 H × W 个变为约 H × W 个 G1 加上 Query 的隐藏高斯。

## 7. 损失

| 损失 | 监督对象 | 定义要点 | 真值来源 | 启用阶段 |
|---|---|---|---|---|
| L_disp | μ₁（内部与边界前景峰） | **逆深度空间 L1，并按参考光圈换算成子光圈视差像素**（见下） | 第一层 GT 深度 | 1 起 |
| L_bimodal | μ₁、μ₂、α̂（边界） | 双峰混合的负对数似然，混合权重取 α̂；只在有可靠前后两层标签的像素计算，其余像素只训练 μ₁ | 子像素网格求交（每像素 4 × 4 条射线）得到的前、后两层深度与覆盖率；不用 Cycles Z 通道（单采样，混色像素上随机落在前景或背景） | 1 起 |
| L_normal | n | 余弦误差 | GT 法向 | 1 起 |
| L_mv | μ₁ | 多视角光度 / 特征一致性，只在静止、有对应的表面计算 | 相邻帧 | 1 起 |
| L_occ | 可见层在子光圈光线上、截断深度之前的累计覆盖 | **误占遮挡空间惩罚，深度截断、双向**（见下）：应显露的光线，可见层在隐藏面深度 z* 之前的累计覆盖 1 − T_vis(z*) → 0；应被前景挡住的光线，前景深度处的累计覆盖 → 1 | 现有 K16 子光圈标签 | 1 起（阶段 1 不计边界像素） |
| L_zero | 整体 | 零光圈渲染（可见层 + 隐藏层）等于输入 I | 输入帧 | 1 起 |
| L_bokeh | 整体 | 完整 K64 与完整光圈 Cycles 真值比较；低分辨率省算力时用两组独立子光圈子集的无偏估计（见下），不直接拿随机子集平均去比完整光圈真值 | Cycles 真值 | 1 起（小权重），3 为主 |
| L_cov | α̂ 与 o、足迹 | 零光圈下可见层在截断深度 z_cut 之前的累计覆盖等于 α̂（只算前景这一层） | 渲染一致性（自监督），须与 L_α 同用 | 2 起 |
| L_α | α̂ | 与 GT 覆盖率比较 | 子像素网格求交的几何覆盖率为主（能处理同一物体自遮挡），Cryptomatte 可选 | 1 起（几何覆盖率），2 起兼用于外观 |
| L_F | F̂ | 边界像素的前景颜色 | 单独渲染的前景（背景透明） | 2 起 |
| L_comp | α̂、F̂ | I ≈ α̂ F̂ + (1 − α̂) B_gt，仅合成数据 | 剥离得到的 B_gt | 2 起 |

**L_disp 的光学含义：物理光圈尺度归一化的逆深度损失。** 薄透镜下带符号的 CoC（同时决定子光圈视差的大小与方向）为

c = K_f · (1/z − 1/d_f)，K_f = A · f · d_f / (d_f − f)。

因此带符号 CoC 的误差 |Δc| = K_f · |Δ(1/z)| 是严格等式。不带符号的 CoC 直径只满足上界：预测深度与真值位于焦平面两侧时，直径可能相同而视差方向相反，这正是带符号形式要惩罚的情况。按仓库内参（等效 50 mm、36 mm 传感器），d_f/(d_f − f) 在 d_f = 1.4 m 时约为 1.037、远焦更接近 1，所以 K_f 随焦点变化在 4% 以内。在逆深度空间监督、乘以参考光圈（f/1.4）下的 A · f / 像素尺寸，即按子光圈视差像素衡量深度误差，同时保持可见层与焦点无关（原则 4）；边界像素再加权。【判断】这能解释附十三中 DepthSplat 的近焦问题：近处前景的逆深度误差大，换算成视差也大。L_disp 只是几何代理，最终光学质量由 L_bokeh 与渲染评价决定。

**L_occ 与 L_cov 的共同量：截断深度的透射率。** 对第 k 条子光圈光线、像素 p，记 T_vis(z) 为可见层中深度小于 z 的高斯累计后的透射率。

- L_occ：在应显露的光线上惩罚 1 − T_vis(z*)，z* 为该光线真实击中隐藏面的深度。只统计隐藏面之前的错误遮挡，不要求整条光线上的可见层覆盖为 0。在应被前景挡住的光线上，要求前景深度处的累计覆盖接近 1，防止模型靠整体降低前景不透明度来降低损失。
- L_cov：同一个量在中心视角、截断深度 z_cut 下的特例。
- 阶段 1 边界尚未拆分，不透明的混色像素必然挡在 z* 之前，因此阶段 1 的 L_occ 不计边界像素（GT 覆盖率 < 1 的像素）。
- 【事实】gsplat 标准接口不直接输出按每像素深度截断的透射率，阶段 1 前需小改光栅化，或用分深度区间渲染近似。

**随机子光圈的偏差。** 若用随机子集 S 的平均 Î_S 与完整光圈真值 I 比较，E‖Î_S − I‖² = ‖E[Î_S] − I‖² + Var(Î_S)。多出的方差项会奖励缩小子光圈之间的差异（例如把深度往焦平面收），直接损害虚化。正式光学损失用完整 K64。低分辨率省算力时，每步独立抽取两组子集 S₁、S₂，损失取逐像素 (Î_S₁ − I)·(Î_S₂ − I) 的均值：两组独立，期望等于偏差平方、不含方差项；配合分层抽样降低单步噪声。也可用 GT 几何高斯按同一子光圈渲染，作为逐子光圈伪真值。

**L_occ 的地位。**【判断】L_occ 与 L_bokeh 是 OVG-Net 区别于 NVS 类前馈高斯网络的根本：NVS 模型的目标是"换个视角好看"，会主动填补遮挡；我们的目标是"该透明的地方透明，该露背景的地方让出来"。

**训练用几何**：第二版可见层网络从第一步起就以实际预测先验（SHARP 校准深度、DepthSplat、三角化）为输入，**不做 GT 几何热身**，GT 只作监督（与 13.4 第 2 条一致），使阶段 1a 的结果直接回答"网络能否修正实际估深误差"。第一版 Query 重训（13.7 第 3 项）沿用附十三的训练课程。

### 阶段 2：边界拆分

- 冻结几何头，训练 F̂、o、足迹（α̂ 继续微调）；按第 4.1 节在第一遍查询边界背景并确定拆分 b，Query 读取 μ₂、α̂；

  - B_gt 也无提升：边界拆分本身收益不足，保留"不拆分"，精力回到几何与记忆；
  - B_gt 有提升、换成预测后下降：瓶颈在记忆 / 候选质量，转向第 5 节第 3 点；
- 指标重点：边界 ±2 px、近焦焦内、远焦可恢复区、假半透明率。

### 阶段 3：联合光学训练

- 先冻结 Query、对可见层施加 K64 虚化损失，再逐步联合微调；
- 训练初期可用 GT 隐藏层作受控辅助，之后必须切换为实际记忆与预测隐藏层，消除训练与推理差异；
- 问题：整个系统能否在留出集超过 A、R1+R2 与 Dr.Bokeh（Dr.Bokeh 的输入口径按 B2 阶段记录说明）。

### 阶段 4：时序与动态

- 运动人物、手持视频、连续推焦；可见层时序适配；Query 保留静态记忆，拒绝把动态物体写入静态背景；
- 时序损失区分真实运动与闪烁，不惩罚所有相邻帧差异。

| 阶段 | 可见层 | 隐藏层 | 关键问题 |
|---|---|---|---|

| 1 | 训练几何 | GT → 第一版 Query | 几何差距收回多少 |

| 4 | 时序适配 | 时序一致检索 | 动态与连续推焦 |

## 9. 推理流程（两遍式）

以 100 帧视频为例：

1. **第一遍**：前端估计位姿与深度先验 → 建立初步记忆 → OVG-Net 逐帧输出可见表面 → 用修正几何重新融合记忆并冻结 → 为候选边界像素查询正后方背景并确定拆分 b。得到每帧可见层（含拆分决定与边界背景）、共享静态记忆、表面身份与候选索引。
2. **第二遍**：给定焦点轨迹 d_f(t)（如 1.4 m → 5.0 m）与光圈。每帧读取可见层 → 按焦点与光圈确定环带查询区域 → Query 输出环带隐藏高斯 → 足迹次序合成 → K64 渲染。
3. 改变焦点时不重跑前端与可见层；新焦点或更大光圈需要此前未查询的区域时，补充执行 Query；与焦点无关的隐藏高斯可缓存复用。

## 11. 消融与论文贡献

### 11.1 计划中的消融

1. 可见层：OVG-Net vs 第一版显式层 vs SHARP（同一 Query）；
2. 几何：单一先验 vs 多先验融合 vs 加局部多视角修正；L_disp 用逆深度视差换算 vs 普通深度 L1；
3. L_occ 有 / 无、单向 / 双向；L_bokeh 有 / 无；
4. 边界拆分有 / 无；边界背景 B_gt vs Query 预测；
5. 次序规则：中心像素 O1 vs 足迹版本；
6. 兜底 F2 有 / 无；
7. 记忆是否用修正几何重新融合。

### 11.2 贡献组织

研究问题：怎样从单目视频前馈预测真实可见表面，同时为其他帧观测到的隐藏表面留出正确的光学可见空间？

1. **面向物理光圈的可见表面网络（Aperture-Aware Visible Surface Reconstruction）**：只沿射线移动的面元、双峰边界、深度截断的误占遮挡空间惩罚（L_occ）与物理光圈尺度归一化的逆深度监督，使可见层只表达看得见的部分，并在子光圈下为背景让出空间。
2. **观测证据驱动的隐藏表面恢复与可见性一致合成（Observation-Guided Hidden Surface Recovery）**：部分与完全遮挡统一由 Query 从视频真实观测恢复，按足迹次序与可见层合成，在该遮挡时被遮挡、该显露时正确显露。

连续调焦、跨帧共享记忆与时序一致性作为系统能力验证。只有消融证明"OVG-Net 相比固定显式层有额外价值""Query 相比规则检索与补全有额外价值""联合训练相比独立训练再拼接有额外价值"，才能各自成为贡献；是否再抽出独立的联合可见性贡献，由消融决定。

### 11.3 与相关工作的区别

| 工作 | 做了什么 | 我们的区别 |
|---|---|---|
| Dr.Bokeh（CVPR 2024） | 单图抠图分层，背景靠补全，可微遮挡感知虚化 | 视频输入；背景来自有证据的记忆；三维高斯 + 子光圈物理渲染 |
| SLIDE（ICCV 2021） | 单图软分层，用于 3D 照片 | 同上；分层由虚化与 L_occ 驱动 |
| BokehMe、MPIB | 单帧渲染 / 分层 + 补全的虚化 | 视频多帧取回真实被遮挡内容 |
| SHARP 等前馈 NVS 高斯 | 每像素多层高斯，补全遮挡区 | 可见层被明确禁止占据遮挡空间 |
| DepthSplat | 多视角代价体 + 单目特征的深度与高斯 | 作为几何先验之一；只在局部做多视角修正 |
| SMD-Nets 等双峰 / 混合深度 | 用双峰深度去除飞点 | 背景峰作为隐藏层的几何锚点 |
| 2DGS、PAGaS | 面元 / 只沿射线移动的高斯 | 作为结构约束采用，不算贡献 |
| MatAnyone 等视频抠图 | 用记忆传播 α | 记忆提供背景颜色与几何，而不只是 α |
| PhGS | 指出单图前馈高斯深层高斯没有固定角色 | 我们给出明确的可见 / 隐藏角色划分与约束 |

已核实存在：混合密度深度（arXiv 2606.02552）、Fix False Transparency（NeurIPS 2025，arXiv 2510.15736）。Geometry Gaussians（arXiv 2606.05124）规划方未能打开原文，引用前需核实。

## 12. 风险与待定事项

1. **数据**：方案已定（第 13 节）；规模随里程碑扩充，不作为开训条件。
2. **细结构类无有效数据**：5 个细结构场景（含细杆纹理下限修正后）均未通过细杆内部的相位检查，而栏杆类正是可见层最应证明价值的场景。处理办法见 13.5（轮廓覆盖率与内部纹理分项评价，加粗样本另归宽度档）。
3. **α 与 F 的歧义与域差距**：只有合成数据有 α、F 真值；真实视频只能用 L_zero、L_mv 弱监督。外观头输入尽量用局部特征，合成数据做强颜色增强。
4. **记忆空窗**：前几帧、相机几乎不动、背景从未露出的场景拿不到可信背景，只能回退"不拆分"。结果按"有 / 无记忆背景"分组统计。
5. **边界误判**：内部像素被误判为边界会产生假半透明，统计假半透明率。
6. **多视角对应不可靠**：相机运动小、动态物体、细结构缺纹理时局部修正可能失效；网络必须能输出低可信度并回退到先验。
7. **几何坐标不一致**：可见层修正后，记忆、候选与放置标签必须按新几何重算（第一遍 ③），否则会重演附十二。
8. **位姿**：全部现有实验使用 GT 位姿；纯 RGB 设定下位姿误差的影响尚未评价。
9. **算力与存储**：现有 9 个场景缓存约 51.7 GiB，按此比例扩到百级场景不可行，需精简缓存；可见层训练可能需要 96GB 训练机，按 AGENTS 1.8 先核算。

### 13.0 原则

1. **按标签类型拆分数据来源。** 每个样本只带它真实具有的标签，只计算对应损失；不具备某种标签的数据不构造该标签。

3. **规模是扩充目标，不是开训条件。** 下文所有规模都是**首轮扩充预算**。阶段 0 现有数据已足够；阶段 1 只要首批有效样本具备本阶段所需标签即可开始训练，后续分片到位后纳入，并记录实际采样比例。

5. **后续阶段保留前面阶段的数据**，按配比继续抽样，防止遗忘。

### 13.4 数据规则

1. **防泄漏**：GT 深度、表面身份、剥离背景与放置标签只进损失，永远不进网络输入或观测记忆；R 档的留出目标帧从输入记忆中排除。

   - **模拟 B_mem**：只在阶段 2a 的 A 档批次使用，必须经过错位、缺洞与噪声扰动；C 档批次与阶段 2b 起，B_mem 必须来自实际记忆（第 4.2 节，M^0 在当前帧的投影）。【判断】否则网络可能过度信任 B_mem，因为模拟误差与真实记忆误差的分布不同。
   - **GT 隐藏层替身**：只作为渲染中的受控替身参与可见层的梯度计算，不进网络输入、不进观测记忆；仅限阶段 1（先 GT、后换 Query）、阶段 2 的 B_gt 对照与阶段 3 初期的受控辅助。
2. **几何输入以真实先验为主**：始终使用 SHARP 校准深度、DepthSplat、三角化的实际预测；Any-to-Bokeh 式扰动（弹性形变、噪声、形态学膨胀与腐蚀，集中在边界）只作为叠加增强。可见层与隐藏层使用同一份扰动后的几何，保证误差相关、坐标一致。

4. **按场景类型扩充**：变化资产、布局、遮挡类型（大面积、薄边界、稀疏孔洞、多层、弱纹理、掠射、小平移）与相机运动，而不只换随机种子；样本量按场景计，不与帧数、光学配置数混算。B 档素材**先用 Poly Haven（CC0）**，程序化世界与电影资产后移。

### 13.5 细结构类

细结构保留为**必测类别**。附十三的失败记录测的是**细杆内部**（已去除遮挡轮廓）的半像素相位误差，因此"轮廓对亚像素位置敏感"不能解释全部失败；在现有 BOX 滤波设置下，2 倍超采样再降采样与原图可以很接近，而图像平移半个像素后仍不稳定，所以**不能用 2 倍超采样单项放行**。有效性检查改为把两种误差分开：

1. **轮廓像素**：用独立的高密度子像素求交得到前景几何覆盖率，在原位置与平移半像素的位置分别与各自参考值比较。细杆平移后覆盖率从 80% 变成 30%，只要两处都与参考一致，就是有效样本。
2. **有足够纯内部像素的细杆**：继续检查内部纹理的相位稳定性（原阈值）。
3. **窄到没有纯内部像素的细丝**：内部纹理一项记为不适用，用第 1 项的覆盖率评价。
4. 2 倍超采样对照保留为辅助检查，不单独决定放行。
5. 若需加粗细杆，加粗后的样本归入较粗的宽度档，原来的细丝难例保留，以便最后报告方法能处理多细的结构。
6. **内部纹理相位超限的固定动作（降级使用）**：轮廓覆盖率检查通过、但内部纹理相位超限的细杆，把其内部纹理像素从对纹理敏感的指标与损失（零光圈、L_bokeh 的逐像素误差）中屏蔽，几何、覆盖率与可见性标签照常使用，场景保留。
