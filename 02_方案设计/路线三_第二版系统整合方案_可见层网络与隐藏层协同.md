## 1. 设定与目标

- **输入**：单目、全清晰 RGB 视频。不使用深度传感器、双摄或其他额外深度输入；深度与遮挡边界几何由方法自己估计。位姿第一阶段沿用 E1 给定位姿，最终系统至少在估计位姿下评价一次（见第 10 节）。
- **输出**：可连续调焦、可调光圈的视频虚化，由 K=64 物理子光圈渲染生成。
- **核心目标**：场景表示既能在中心视角（零光圈）复现输入，又能在每条子光圈光线下给出正确的遮挡变化——该被挡住的被挡住，该显露的背景以真实观测内容显露。
- **一句话**：可见层诚实地表达"当前真正看见了什么、它在哪里、占了像素多少"；隐藏层用视频中有证据的观测回答"光圈打开后还能看见什么"；两者在同一几何坐标和同一可见性规则下合成。

## 2. 依据：已有实验给出的约束

| 编号 | 【事实】 | 来源 | 对设计的含义 |
|---|---|---|---|

| E-2 | 显式逐像素层零光圈约 63–71 dB（附十二 D0），比 SHARP（A，约 56–67 dB）高；隐藏层前置于可见面贡献了约 88% 的零光圈误差增量 | 附十二 | 像素对齐、只沿射线移动的表示能保住输入；必须有严格的前后次序约束 |

## 3. 系统总体结构

```
单目 RGB 视频 I_{1:T}
  │
  ├─ 几何前端（冻结）
  │     位姿 P_t：第一阶段 E1 给定；之后估计位姿
  │     深度先验 {D_t^k, c_t^k}：SHARP 校准深度、DepthSplat、静止区多帧三角化（各带可信度）
  │     运动掩码 m_t^dyn：沿用 src/c1_regions.py 的 background_and_motion
  │
  ├─ 第一遍：理解场景
  │     ① 用前端几何建立初步观测记忆 M^0（只存经多帧验证的真实观测）
  │     ② 可见层网络 V（第 4 节）逐帧输出可见表面：G_t^vis 与几何锚点（μ₂、b、α）
  │     ③ 用 V 的几何重新融合观测记忆，得到 M^1，并在片段内冻结
  │
  ├─ 第二遍：按焦点 / 光圈生成虚化
  │     ④ 按焦点 d_f、光圈 A 与 V 的几何确定查询区域（环带 ∪ 部分遮挡边界像素）
  │     ⑤ Hidden Query 从 M^1 选择、修正、上色，输出全部背景高斯 G_t^hid
  │     ⑥ 统一合成：足迹次序规则（第 6 节），可选兜底（第 6.3 节）
  │     ⑦ K64 子光圈渲染 → 虚化帧
  │
  └─ 输出：可连续调焦的虚化视频
```

设计原则：

1. **背景只有一个来源。** 任何位于可见面之后的内容——完全遮挡的环带像素和部分遮挡的边界像素——都由 Hidden Query 从观测记忆给出。可见层不放背景高斯，避免重演附十至附十二"两套高斯抢同一空间"的问题。
2. **几何统一。** 可见层修正几何后，记忆、候选与放置标签都在修正后的坐标中重算（第一遍 ③），两遍之间不无限迭代。
3. **长期记忆只存真实观测。** Query 的预测只进短期缓存，不回写长期记忆；可见层的 G1 经多帧验证后才可写入（沿用方案 2.3.1）。
4. **可见层与光圈无关。** 焦点与光圈只作用于查询区域与渲染，可见层每帧只算一次，便于时序稳定与缓存复用。

## 4. 可见层网络（暂名 OVG-Net）

### 4.1 表示：每个像素输出什么

每个像素 p 输出一颗**主表面高斯 G1**，外加只作几何锚点、不渲染的若干量：

| 输出 | 含义 | 约束 |
|---|---|---|
| μ₁(p) | 可见表面沿像素射线的深度 | 高斯中心 = 相机中心 + μ₁ · 射线方向，只有 1 个自由度，不能横向漂移 |
| n(p) | 表面法向 | 决定面片朝向 |
| s₁, s₂(p) | 切平面内两个尺度 | 法向方向尺度固定为很小，做成扁平面元（参照 2DGS 的 surfel） |
| α̂(p) | 前景在该像素的覆盖率 | 内部像素为 1 |
| F̂(p) | 纯前景颜色（线性 RGB） | 内部像素严格等于输入 I(p)；只在边界生效 |
| b(p) | 边界概率 | 决定该像素是否按边界处理 |
| μ₂(p), π(p) | 双峰深度中的背景峰与前景权重 | μ₂ 只作为传给 Query 的背景几何锚点，可见层不在 μ₂ 处放高斯 |
| c(p) | 几何可信度 | 供记忆融合与 Query 使用 |

解码规则：

```
对每个像素 p：
  若 b(p) < τ（内部）：
      G1：位置 μ₁，颜色 I(p)，不透明度 1，朝向 n，尺度 (s₁, s₂)
  若 b(p) ≥ τ（边界）：
      G1：位置 μ₁，颜色 F̂(p)，不透明度 o(p)，朝向 n，尺度 (s₁, s₂)
      向 Hidden Query 登记：该像素需要背景，背景深度锚点 μ₂(p)，前景覆盖 α̂(p)
  回退：若 Query 在该像素没有可信背景，则该像素不拆分——G1 颜色取 I(p)、α̂ = 1（等同第一版显式层）
```

**α̂ 与不透明度的关系。** 二维覆盖率不能直接当作单颗高斯的不透明度：像素覆盖同时取决于不透明度、足迹大小和相邻高斯的重叠。不推导解析映射，而用渲染一致性约束——零光圈下只渲染 G1 得到的覆盖率应等于 α̂（L_cov，见第 7 节），让网络学会 o 与 (s₁, s₂) 的组合。这同时约束足迹，减少缝隙。

**为什么这样分工。**【判断】把 I 拆成 F 与 B 在代数上欠定：B 未知时 3 个方程、7 个未知数；B 已知也还有 3 个方程、4 个未知数。可见层自己猜 B 就是在幻觉被遮挡内容，正是 SHARP 的老问题。所以可见层只回答它看得见的部分（边界在哪、前景占多少、背景大约多深），背景颜色由有证据的记忆通过 Query 回答。

### 4.2 输入

| 输入 | 维度 | 说明 |
|---|---|---|
| 当前帧 I_t | H × W × 3 | 线性 RGB |
| 相邻帧 | N × H × W × 3，N = 2–4 | 附位姿与内参 |
| 深度先验 {D^k, c^k} | K × H × W × 2 | SHARP 校准深度、DepthSplat、静止区三角化，各带可信度；缺失处可信度为 0 |
| 运动掩码 m^dyn | H × W | 运动区不参与多视角修正 |
| 记忆背景 B_mem（阶段 2 起） | H × W × 3，附可信度与有效掩码 | 来自 M^0 在当前帧的投影；只作为边界拆分的辅助输入 |

光圈与焦点**不**作为输入（原则 4）。

### 4.3 网络结构

```
I_t ──► 冻结 ViT 编码器（DINOv2 或 DA 系列）→ H/14 × W/14 × C      语义与全局几何
I_t ──► 轻量 CNN 高分辨率分支              → H/2 × W/2, H/4 × W/4    边缘细节
{D^k, c^k}, m^dyn, (B_mem) ──► 小卷积编码  → H/4 × W/4
        └──► DPT 式解码器逐级融合          → H × W × 64（逐像素特征 φ）

局部多视角修正（只在 m_ref = 低可信区域 ∪ 深度断层附近 ∖ 运动区）：
   以当前融合深度为中心、按可信度取 S = 8 个逆深度假设
   → 相邻帧特征按位姿投影到每个假设 → 与 φ 做相关 → 稀疏代价 |m_ref| × S
   → 软最大加权 → 逆深度修正量 Δ(1/z)

输出头（作用于 φ 与代价特征）：
   几何头：μ₁、μ₂、π、n、c、b
   外观头：α̂、F̂（阶段 2 启用）
   足迹头：s₁、s₂、o
```

【判断】只在局部做多视角匹配，不建完整代价体：DepthSplat 已给出全局多视角几何，网络只需修正最常出错的位置（前景边缘、低可信区域），算力也省很多。【假设】参数量在数百万量级（ViT 冻结），需实测。

### 4.4 与第一版显式层的区别

| | 第一版显式层（D0 / D1） | 第二版 OVG-Net |
|---|---|---|
| 是否训练 | 不训练，规则生成 | 训练 |
| 位置 | 单一估计深度，固定 | 多先验融合 + 局部多视角修正，只沿射线 |
| 边界 | 整个像素颜色当作不透明前景 | 双峰深度 + 覆盖率 + 纯前景色，背景交给 Query |
| 形状 | 各向同性小高斯（5 × 5 细分） | 按法向的面元，足迹可学 |
| 与隐藏层 | 只靠事后次序规则 | 登记边界需求、提供背景深度锚点，共享几何 |

## 5. Hidden Query 的改动

第一版 Query（约 3.8 万参数，候选选择 → 几何修正 → 重投影 → 外观融合）保留，改动如下：

1. **查询区域扩展**：环带 ∪ 可见层登记的边界像素（b ≥ τ）。部分遮挡与完全遮挡由同一个 Query 负责。
2. **新增输入特征**：可见层的 μ₁、μ₂、α̂、c 与 b。部分遮挡像素上，μ₂ 作为背景深度假设的中心。
3. **在修正后的几何上重新生成候选**：可见层几何更新后，记忆重新融合（第一遍 ③），候选与放置标签按新几何重算。【假设】正确候选覆盖（目前 GT 可恢复区约 35%）会随可见层几何变准而上升。
4. **边界像素的合成要求**：零光圈下应满足 I ≈ α̂·F̂ + (1 − α̂)·C_hid，其中 C_hid 为 Query 在该像素背景处的渲染贡献（由 L_zero 约束，不另设硬规则）。
5. **激活的类别平衡**：附十三 R3 显示类别平衡加权会把误激活从 41.5% 提到 63.7%、漏激活从 53.7% 降到 35.1%；第二版继续作为消融，不预先固定。

## 6. 合成与渲染

### 6.1 次序规则：从中心像素改为足迹

第一版 O1 只检查隐藏高斯中心投影像素的可见深度 z_v（深度 < 1.03 z_v 则推到 1.03 z_v）。附十三 R3 的零光圈泄漏（E-9）说明，高斯足迹覆盖到相邻像素时，可能在前景边缘处位于相邻背景像素之前。第二版规则：

```
对每颗隐藏高斯 h（中心深度 z_h，中心视角 3σ 足迹 Ω_h）：
  1. 若 z_h < 1.03 · z_v(中心像素)：按 O1 推到 1.03 · z_v（不变）
  2. 足迹检查：若存在 p ∈ Ω_h 使 z_v(p) · 1.03 > z_h（h 在 p 的可见面之前），
     先缩小 h 的切平面尺度，使 Ω_h 只覆盖 z_v(p) · 1.03 ≤ z_h 的像素；
     缩到最小足迹仍不满足的，丢弃 h（不作放置标签）
```

训练标签与预测后处理使用同一规则。附十三阶段 0 先实现并统计各步数量（见第 8 节）。

### 6.2 零光圈要求

加入隐藏层后，零光圈相对只渲染可见层的下降 ≤ 0.1 dB 作为护栏；可见层自身零光圈 ≥ 50 dB 作为辅助要求（沿用原定义）。

### 6.3 兜底

第一版 F2（显式层与隐藏层都未覆盖的光线，取 A 在同一子光圈光线上的渲染）保留为可选兜底：它在估计几何下有效（附十三 T1：D0 与 A 在可恢复区基本持平），但它本身是单图模型的猜测。第二版评价同时报告"有 / 无 F2"，论文主结果是否使用 F2 由消融决定。

### 6.4 渲染器

K=64 子光圈渲染器不变。高斯数量从 H × W 个变为约 H × W 个 G1 加上 Query 的隐藏高斯。

## 7. 损失

| 损失 | 监督对象 | 定义要点 | 真值来源 | 启用阶段 |
|---|---|---|---|---|
| L_disp | μ₁（内部与边界前景峰） | **逆深度空间 L1，并按参考光圈换算成 CoC 像素**（见下） | 第一层 GT 深度 | 1 起 |
| L_bimodal | μ₁、μ₂、π（边界） | 双峰混合的负对数似然，前景峰拟合第一层、背景峰拟合剥离后第一隐藏面 | GT 深度 + 现有剥离管线 | 1 起 |
| L_normal | n | 余弦误差 | GT 法向 | 1 起 |
| L_mv | μ₁ | 多视角光度 / 特征一致性，只在静止、有对应的表面计算 | 相邻帧 | 1 起 |
| L_occ | 可见层在子光圈光线上的覆盖 | **误占遮挡空间惩罚**：K16 标签显示某条子光圈光线应击中隐藏面时，可见层在该光线上的累计覆盖应接近 0 | 现有 K16 子光圈标签 | 1 起 |
| L_zero | 整体 | 零光圈渲染（可见层 + 隐藏层）等于输入 I | 输入帧 | 1 起 |
| L_bokeh | 整体 | 从 64 个子光圈中随机取 8–16 个渲染，与 Cycles 子光圈或合成结果比较 | Cycles 真值 | 1 起（小权重），3 为主 |
| L_cov | α̂ 与 o、足迹 | 零光圈只渲染 G1 的覆盖率等于 α̂ | 渲染一致性（自监督） | 2 起 |
| L_α | α̂ | 与 GT 覆盖率比较 | Cryptomatte 类逐物体覆盖率 | 2 起 |
| L_F | F̂ | 边界像素的前景颜色 | 单独渲染的前景（背景透明） | 2 起 |
| L_comp | α̂、F̂ | I ≈ α̂ F̂ + (1 − α̂) B_gt，仅合成数据 | 剥离得到的 B_gt | 2 起 |

**L_disp 的"虚化感知"含义。** 薄透镜下 CoC 直径为

c = A · f · d_f / (d_f − f) · |1/z − 1/d_f|，当 d_f ≫ f 时 c ≈ A · f · |1/z − 1/d_f|。

因此深度误差引起的 CoC 误差 Δc ≈ A · f · |Δ(1/z)|，**与焦点 d_f 无关**。在逆深度空间监督、并乘以参考光圈（f/1.4）下的 A · f / 像素尺寸，就等价于"按对虚化的影响加权深度误差"，同时保持可见层与焦点无关（原则 4）。边界像素在此基础上再加权。这解释了附十三中 DepthSplat 的问题：近处前景的逆深度误差大，换算成 CoC 也大，近焦时直接表现为焦内失焦。

**L_occ 的地位。**【判断】L_occ 与 L_bokeh 是 OVG-Net 区别于 NVS 类前馈高斯网络的根本：NVS 模型的目标是"换个视角好看"，会主动填补遮挡；我们的目标是"该透明的地方透明，该露背景的地方让出来"。

**训练用几何**：估计几何为主；GT 几何只作早期短暂热身（沿用方案 2.5）。

## 8. 训练阶段

开发顺序如下；每个阶段内部带对照，但不设训练前诊断门槛（方案 2.5 固定约定）。

### 阶段 0：第一版收尾，给出基线（立即）

- 默认几何改回原估计几何（E-6），DepthSplat 保留为对照；
- 次序规则改为第 6.1 节的足迹版本，重算放置标签并统计"推后 / 缩小足迹 / 丢弃"的数量；
- 重新训练第一版 Query，在留出集两个焦点上报告学习版、候选 Oracle、D1-Oracle、D0 相对 A 的可恢复区 / 焦内 / 零光圈；
- 补一组留出集 GT 几何参照（D-GT0、D-GT1、GT 几何下的学习版），作为第二版几何能达到的目标量级；
- 产出：第二版要超过的基线与目标。

### 阶段 1：可见层几何

- 训练：μ₁、μ₂、π、n、c、b、足迹与不透明度；外观头不启用（边界按"不拆分"处理，G1 颜色 = I）；
- 隐藏层：先用 GT 隐藏层（对齐、足迹次序），隔离可见层的学习问题；随后换为阶段 0 的 Query；
- 损失：L_disp（CoC 换算）、L_bimodal、L_normal、L_mv、L_occ、L_zero、小权重 L_bokeh；
- 对照：D0（各单一先验）、阶段 0 学习版、D-GT；
- 问题：学习式几何能收回多少"估计几何 → GT 几何"的差距（E-3、E-4），尤其近焦焦内与可恢复区。

### 阶段 2：边界拆分

- 冻结几何头，训练 α̂、F̂、o、足迹；Query 查询区扩展到边界像素并读取 μ₂、α̂；
- 内部对照：边界背景先用 B_gt（Oracle），再换为 Query 的实际预测；
  - B_gt 也无提升：边界拆分本身收益不足，保留"不拆分"，精力回到几何与记忆；
  - B_gt 有提升、换成预测后下降：瓶颈在记忆 / 候选质量，转向第 5 节第 3 点；
- 指标重点：边界 ±2 px、近焦焦内、远焦可恢复区、假半透明率。

### 阶段 3：联合光学训练

- 先冻结 Query、对可见层施加 K64 虚化损失，再逐步联合微调；
- 训练初期可用 GT 隐藏层作受控辅助，之后必须切换为实际记忆与预测隐藏层，消除训练与推理差异；
- 问题：整个系统能否在留出集超过 A、R1+R2 与 Dr.Bokeh（Dr.Bokeh 的输入口径按 B2 阶段记录说明）。

### 阶段 4：时序与动态

- 运动人物、手持视频、连续推焦；可见层时序适配；Query 保留静态记忆，拒绝把动态物体写入静态背景；
- 时序损失区分真实运动与闪烁，不惩罚所有相邻帧差异。

| 阶段 | 可见层 | 隐藏层 | 关键问题 |
|---|---|---|---|
| 0 | 固定显式层（原估计几何） | 第一版 Query 重训 | 基线与目标量级 |
| 1 | 训练几何 | GT → 第一版 Query | 几何差距收回多少 |
| 2 | 训练边界外观（几何冻结） | Query 扩到边界 | 边界拆分是否有价值、记忆是否够 |
| 3 | 联合 | 联合 | 系统能否超过 A 与已有方法 |
| 4 | 时序适配 | 时序一致检索 | 动态与连续推焦 |

## 9. 推理流程（两遍式）

以 100 帧视频为例：

1. **第一遍**：前端估计位姿与深度先验 → 建立初步记忆 → OVG-Net 逐帧输出可见表面 → 用修正几何重新融合记忆并冻结。得到每帧可见层、共享静态记忆、表面身份与候选索引。
2. **第二遍**：给定焦点轨迹 d_f(t)（如 1.4 m → 5.0 m）与光圈。每帧读取可见层 → 按焦点与光圈确定查询区域 → Query 输出隐藏高斯 → 足迹次序合成 → K64 渲染。
3. 改变焦点时不重跑前端与可见层；新焦点或更大光圈需要此前未查询的区域时，补充执行 Query；与焦点无关的隐藏高斯可缓存复用。

## 10. 评价协议

- **配置**：两个焦点（1.4 / 5.0 m）都参与；f/1.4 为主、f/2.0 辅；P2 为主、P1 为辅；Cycles 为主。
- **区域**：全图、焦内、环带、可恢复区、边界 ±2 px、几何无效像素区。
- **指标**：PSNR、patch LPIPS；零光圈 PSNR；CoC 加权深度误差（逆深度误差 × A·f / 像素尺寸）；飞点率（边界处深度落在前后两层之间的比例）；假半透明率（内部像素 α̂ < 1 的比例）；Query 的误激活 / 漏激活 / 正确候选可得率。
- **选择规则**：任何几何版本、规则或超参数的选择只用训练场景，两个焦点合并，同时看可恢复区与焦内；留出集只用于最终报告（E-6 的教训）。
- **位姿**：E1 给定位姿为主；最终系统另报一次估计位姿下的结果。
- **对照**：A（SHARP + A-color）、R1+R2、第一版学习版、Dr.Bokeh、GT 几何 Oracle。

## 11. 消融与论文贡献

### 11.1 计划中的消融

1. 可见层：OVG-Net vs 第一版显式层 vs SHARP（同一 Query）；
2. 几何：单一先验 vs 多先验融合 vs 加局部多视角修正；L_disp 用逆深度 CoC 换算 vs 普通深度 L1；
3. L_occ 有 / 无；L_bokeh 有 / 无；
4. 边界拆分有 / 无；边界背景 B_gt vs Query 预测；
5. 次序规则：中心像素 O1 vs 足迹版本；
6. 兜底 F2 有 / 无；
7. 记忆是否用修正几何重新融合。

### 11.2 贡献组织

1. **面向物理光圈的可见表面网络**：只沿射线移动的面元、双峰边界、误占遮挡空间惩罚（L_occ）与虚化感知的逆深度监督，使可见层只表达看得见的部分，并在子光圈下为背景让出空间。
2. **观测证据驱动的隐藏表面恢复与可见性一致合成**：部分与完全遮挡统一由 Query 从视频真实观测恢复，按足迹次序与可见层合成，在该遮挡时被遮挡、该显露时正确显露。

连续调焦、跨帧共享记忆与时序一致性作为系统能力验证。只有消融证明"OVG-Net 相比固定显式层有额外价值""Query 相比规则检索与补全有额外价值""联合训练相比独立训练再拼接有额外价值"，才能各自成为贡献。

### 11.3 与相关工作的区别

| 工作 | 做了什么 | 我们的区别 |
|---|---|---|
| Dr.Bokeh（CVPR 2024） | 单图抠图分层，背景靠补全，可微遮挡感知虚化 | 视频输入；背景来自有证据的记忆；三维高斯 + 子光圈物理渲染 |
| SLIDE（ICCV 2021） | 单图软分层，用于 3D 照片 | 同上；分层由虚化与 L_occ 驱动 |
| BokehMe、MPIB | 单帧渲染 / 分层 + 补全的虚化 | 视频多帧取回真实被遮挡内容 |
| SHARP 等前馈 NVS 高斯 | 每像素多层高斯，补全遮挡区 | 可见层被明确禁止占据遮挡空间 |
| DepthSplat | 多视角代价体 + 单目特征的深度与高斯 | 作为几何先验之一；只在局部做多视角修正 |
| SMD-Nets 等双峰 / 混合深度 | 用双峰深度去除飞点 | 背景峰作为隐藏层的几何锚点 |
| 2DGS、PAGaS | 面元 / 只沿射线移动的高斯 | 作为结构约束采用，不算贡献 |
| MatAnyone 等视频抠图 | 用记忆传播 α | 记忆提供背景颜色与几何，而不只是 α |
| PhGS | 指出单图前馈高斯深层高斯没有固定角色 | 我们给出明确的可见 / 隐藏角色划分与约束 |

思路稿中引用的"混合密度深度（2606.02552）"与"Fix False Transparency"两篇，写入论文前需核实出处。

## 12. 风险与待定事项

1. **数据（待用户决定）**：见第 13 节。
2. **细结构类无有效数据**：5 个细结构场景（含细杆纹理下限修正后）均未通过相位检查，而栏杆类正是可见层最应证明价值的场景。需查明相位检查在细杆上的定义是否合适，或调整细杆生成方式。
3. **α 与 F 的歧义与域差距**：只有合成数据有 α、F 真值；真实视频只能用 L_zero、L_mv 弱监督。外观头输入尽量用局部特征，合成数据做强颜色增强。
4. **记忆空窗**：前几帧、相机几乎不动、背景从未露出的场景拿不到可信背景，只能回退"不拆分"。结果按"有 / 无记忆背景"分组统计。
5. **边界误判**：内部像素被误判为边界会产生假半透明，统计假半透明率。
6. **多视角对应不可靠**：相机运动小、动态物体、细结构缺纹理时局部修正可能失效；网络必须能输出低可信度并回退到先验。
7. **几何坐标不一致**：可见层修正后，记忆、候选与放置标签必须按新几何重算（第一遍 ③），否则会重演附十二。
8. **位姿**：全部现有实验使用 GT 位姿；纯 RGB 设定下位姿误差的影响尚未评价。
9. **算力与存储**：现有 9 个场景缓存约 51.7 GiB，按此比例扩到百级场景不可行，需精简缓存；可见层训练可能需要 96GB 训练机，按 AGENTS 1.8 先核算。
