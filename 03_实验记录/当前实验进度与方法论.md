## 1. 研究主线

**2026-11-02 起转向“动态 3DGS + 光学虚化”路线（原路线三）。** 用户决定 V2（隐式几何/焦点相对表示）先放着，改为研究利用 3D Gaussian Splatting 做视频虚化，目标投稿 CVPR/ICCV/ECCV 级别会议。当前处于**路线三前期准备与最小验证阶段**，方法仍为候选，尚未训练。

候选主张（**未验证的研究假设**，读完论文后再讨论冻结）：虚化是镜头光圈内光线的积分；视频中前景边缘背后被挡住的背景常在其他帧出现。用动态 3DGS 汇聚整段视频的观察，补全“光圈能看到的被遮挡内容”，再做有限光圈渲染，期望得到物理正确的半透明边缘、跨帧一致的跟焦，以及“重建一次、任意改焦点/光圈”。

此前以 Any-to-Bokeh（ATB）为核心的复现、效率与失败分析成果保留为**动机证据与对比 baseline**：ATB 是 2.5D（逐帧深度→CoC）方法，已证实离焦条件错误会造成主体局部细节损失（B36），每换一次焦点/光圈需重跑扩散（模型段采样峰值约 38.47 GiB，VAE 约占 81% 时间）；ATB 风格的合成数据是前景/背景两平面拼贴，无法评价三维几何（见第 3 节 V2 行）。课题原文的低帧率双目深度等仍为历史提案；手机多摄同步视频可作为本路线的后续扩展，需确认数据来源。

**候选创新点（讨论中，未验证、未冻结）**：

1. **C1 光圈尺度重建**：虚化只需原相机附近光圈大小的视角，单目动态重建在此范围内可能足够准确；这是整条路线的关键前提，需最先验证。
2. **C2 光圈可见性驱动的遮挡补全**：只补焦点/光圈决定的、前景边缘外那条被挡窄带；先从其他时刻取回，从未见过的部分再用生成先验并标不确定性。对焦背景时补全要求最高。
3. **C3 物理光圈渲染**：利用 3DGS 速度做光圈内多视点采样，支持部分遮挡、光圈形状、猫眼，以及从 LDR 恢复高光（Vid2Bokeh 未做 HDR）。
4. **C4 三维一致的动态虚化基准**：光线追踪薄透镜真值，含多焦点/光圈、部分遮挡与高光。
5. **C5（后续）**：以该流程为数据引擎蒸馏前馈视频模型；InfiniSplat v2 开源后前馈初始化 + 少量逐视频细化也值得讨论。

**主要风险**：单目动态重建失败（快速运动、非刚体、反光、细结构）；生成补全幻觉；与 Vid2Bokeh、DoF-Gaussian/CineCtrl 团队的撞题风险。相关工作检索截至 2026-11-02，投稿前需复查，不写“首次”。

## 4. 关键决策及其依据

| 决策 | 依据 | 影响 |
|---|---|---|
| 2026-11-02 转向动态 3DGS + 光学虚化路线 | 用户决定；ATB 类 2.5D 方法在部分遮挡、逐帧几何与重复计算上有结构性局限，V2 未找到 VGGT 特有收益 | V2、Student、ATB 效率优化暂停；旧方案与论文归档，主线文献按阅读顺序入库 |
| 采用 failure-driven 而非 proposal-driven 设计 | 旧提案只是候选，创新须对应明确瓶颈或失败场景 | 3DGS 路线同样先验证关键前提（C1），不把模块拼接当创新 |
| 已冻结 baseline 结果保持不变 | Synthetic/DAVIS/效率表已按协议冻结，配置选择有记录 | 作为后续对比基础，不因新方法回调；MagicBokeh B、Dr.Bokeh GT Alpha、DeepLens 饱和等权限与限制继续披露 |
| 效率比较统一在日常机同一 GPU、同一计时边界 | AGENTS 1.8 | 旧 96GB 卡结果保留硬件标注，不跨卡算加速比 |
| 低帧率专项退出主线 | 导师确认不必作为硬创新 | 历史设计保留，未来按需恢复 |
