## 1. 研究主线

**2026-11-02 起转向“动态 3DGS + 光学虚化”路线（原路线三）。** 用户决定 V2（隐式几何/焦点相对表示）先放着，改为研究利用 3D Gaussian Splatting 做视频虚化，目标投稿 CVPR/ICCV/ECCV 级别会议。C1 前提验证阶段已于 2026-11-11 结束（用户决定），当前进入**第一版网络实现与小规模训练**，方法仍为待验证的设计，尚未训练。

候选主张（**未验证的研究假设**，2026-11-12 更新，见方案 2.4）：虚化是镜头光圈内光线的积分；当前帧被遮挡、但大光圈能看到的背景常在视频其他帧出现。第一版用像素锚定的可见层加上视频静态观测记忆，由光圈条件的 Query 查询、修正并重建光圈潜在可见的真实隐藏表面（C-1），再做物理子光圈渲染；同一份记忆与隐藏表面跨帧、跨焦点复用，带来时序一致的连续调焦（C-3，作为性质）。可见层本身（SHARP 几何 + 颜色锚定）只作系统组成，不作为贡献。

此前以 Any-to-Bokeh（ATB）为核心的复现、效率与失败分析成果保留为**动机证据与对比 baseline**：ATB 是 2.5D（逐帧深度→CoC）方法，已证实离焦条件错误会造成主体局部细节损失（B36），每换一次焦点/光圈需重跑扩散（模型段采样峰值约 38.47 GiB，VAE 约占 81% 时间）；ATB 风格的合成数据是前景/背景两平面拼贴，无法评价三维几何（见第 3 节 V2 行）。课题原文的低帧率双目深度等仍为历史提案；手机多摄同步视频可作为本路线的后续扩展，需确认数据来源。

## 2. 当前状态与下一步

### 当前阶段：前期验证结束，进入第一版网络实现（2026-11-11 用户决定）

**C1 前提验证阶段结论**（B2 至 S1d；详细过程、数值与证据入口见[阶段完整记录](历史阶段记录/2026-11-11_路线三C1前提验证阶段完整记录.md)；结论只适用于受控 Blender 场景，E1 使用 GT 位姿）：

1. **物理光圈渲染可行**：K=64 子光圈积分对 Cycles 为 52.6 / 53.9 dB（U0），作为当前质量参考；逐高斯解析模糊画质不达标，不采用（L1）。
2. **可见层方向确定**：学习式几何 + 像素颜色锚定；校准后相对校准 O3-DA3 全图 +0.42 / +0.78 dB、焦内 +2.8 / +2.5 dB（S1c，描述性）。MoVieS 不作骨干（A1、C0–C4）。
3. **隐藏层有价值**：真实可恢复隐藏层在校准几何下近 / 远焦全图 +0.20 / +1.47 dB、可恢复区 +0.98 / +3.19 dB，未校准时约为 0（S1c）。
4. **瓶颈已定位**：候选几乎都在（投影覆盖约 99.8%），但深度正确的只有约 23%；深度错位与来源边缘混色大量重叠，单因素替换不可加；R2 来源边缘剔除收回约 59% / 58% 的可恢复区 MSE 差距，正式 R4 未过 P6（S1d，[总记录](records/route3-sharp-s1d-2026-11-11-summary.json)、[解释](records/route3-sharp-s1d-2026-11-11-interpretation.json)、[收回比例](records/route3-sharp-s1d-2026-11-11-gap-recovery.csv)）。
5. **未解决**：真实视频位姿（E2 阻塞）；高光截断主导全图误差；证据只来自一个受控场景。

**决定**（方案 4.15）：结束前期验证，不再增加训练前的门槛实验；R1+R2 以 S1d 中间结果作开发参考，论文评价时在独立场景用冻结协议重比。进入第一版网络实现与小规模训练，首版只恢复静态隐藏背景。预注册只用于论文主表与关键消融，开发迭代只记录。已冻结的实验与结论全部保留，新训练结果不覆盖。

**第一版方法**（方案 2.3 ③、2.3.1、2.5）：像素锚定可见层（固定）+ 静态观测记忆（长期记忆只存验证过的观测，预测只进短期缓存）+ 候选驱动的光圈条件 Query + 几何 / 外观联合修正（几何更新后重新投影读取来源颜色）+ K=64 渲染。训练输入用校准估计深度或带误差扰动的深度；先用剥离隐藏层真值直接监督，再加渲染损失。

**下一步**（执行提示词见方案附七）：

1. 第一批合成数据管线：**只做静态场景 + 带平移视差的运动相机**（运动前景放第二批），2 个场景试点实测成本后扩到 3–5 个，再按独立场景划分训练 / 留出，B2-high 只作开发评测；训练课程 S2a（256 / 5 帧）→ S2b（512 / 13 帧）→ S3-lite（方案 2.5，2026-11-12）；
2. 第一版网络实现与小规模训练；评分沿用 S1d 脚本，对照校准 A-color、R1+R2、轻量候选融合、完整 Query 解码；
3. 转向点：训练 1–2 周后若在留出场景上仍明显达不到 R2，停下重新判断；
4. 并行、不阻塞训练：E2′ 真实视频位姿来源；视频补全分层基线。
