## 0. 完整数据流（先看这一段）

Vid2Bokeh 首先使用 **DL3DV-10K** 的普通视频，选取若干关键帧及相机参数，围绕关键帧布置规则的虚拟子孔径相机阵列，并利用 **LaCT 前馈新视角合成模型**生成每个参考时刻的 **25×25=625 个子视角 RGB**，形成密集光场。为了适应不同场景的视差，生成过程结合光流估计调整虚拟相机基线。之后不需要预测逐像素单目深度来生成散焦标签，而是直接在光场上选择对焦平面参数 $\kappa$ 与光圈采样半径 $a$，对各子视角平移并积分，得到指定光学状态下的 RGB 图像。

对同一个光场随机选取两套参数 $(\kappa_1,a_1)$、$(\kappa_2,a_2)$，渲染两张内容相同但景深不同的图像 $I_{\rm in}$ 与 $I_{\rm gt}$，并计算相对控制量 $\Delta\kappa=\kappa_2-\kappa_1$、$\Delta a=a_2-a_1$。**这一步是离线光场数据支撑的训练配对生成流程**。下游将 $I_{\rm in}$ 经 VAE 编码成源潜变量；将 $I_{\rm gt}$ 的潜变量加噪，作为扩散训练的目标分布；把 $\Delta\kappa,\Delta a$ 经过 Fourier Features 与 MLP 变成条件嵌入，引导 SDXL 风格的 U-Net 学会双向对焦与景深编辑。

**推理时**只需输入单张 RGB 图像和参数偏移 $(\Delta\kappa,\Delta a)$，无需重新加载原始视频、LaCT、625 张光场、逐像素深度图或目标 GT。

```text
【数据生成：用于构造监督】

             │
             ▼

             │
             ▼

             │
             ▼

             │

             │

                    │                      │
```

## 1. 研究目标、核心问题与贡献

### 1.1 任务定义

- **Focus（对焦）**：调整哪个视差/深度平面最清晰。
- **DoF（Depth of Field，景深）**：控制偏离对焦平面的区域模糊范围和强度。
- **Bidirectional（双向）**：既可增强散焦，也可减弱散焦；可从前景对焦切换到背景对焦，反之亦然。
- **输入和输出**：最终编辑器以**单张 RGB + 两个连续控制偏移**为输入，生成一张目标景深 RGB；不是直接预测 3DGS，也不直接输出连续视频。

### 1.2 为什么现有数据不够好

1. **真实设备采集**：光学效果可靠，但专门相机、相机阵列或焦点扫描难以扩展到大量场景。
2. **RGB + 单目深度合成**：易扩展，但单层深度会在反射、透明和细网格/枝条附近出错；错误散焦标签会传递到编辑网络。
3. **本文路线**：利用普通视频的多视角信息合成密集光场，通过孔径积分形成散焦，不要求为每个像素先指定唯一深度。

### 1.3 三项主要贡献【论文/官方】

- 提出普通视频 → 高密度光场 → 连续可控散焦监督的数据构建流程。
- 构建 **100K+ 光场样本**，采样自约 **10K 段视频**，在场景规模与几何保真之间取得平衡。
- 使用这套数据训练相对光学参数条件化的扩散模型，支持单图像双向对焦和景深编辑，在复杂遮挡和反射示例中改善视觉几何一致性。

## 2. Related Work（简述）

| 路线 | 典型形式 | 主要限制 |
|---|---|---|
| 真实景深采集 | 同一场景多焦点/多光圈摄影 | 采集成本高，场景数量有限 |
| 深度驱动景深生成 | RGB → 单目深度/视差 → CoC → 散焦 RGB | 深度边界、反射、透明、遮挡层次可能错误 |
| 去模糊再渲染 | 模糊 RGB → 清晰图 → 景深渲染 | 两阶段误差累积，可能恢复错误纹理 |
| 光场摄影 | 相机阵列/光场相机 → 规则子视角积分 | 对专门设备依赖高 |
| 本文 | 普通视频 → 合成密集光场 → 光场景深配对 GT → 单图扩散编辑 | 需要可靠的新视角生成，并有生成式编辑的真实性局限 |

## 3. 数据构建：普通视频 → 25×25 光场

### 3.1 输入和输出【论文/官方】

- **视频来源**：DL3DV-10K，附带相机位姿信息；为不同视频选择参考关键帧。
- **每个参考帧**：建立以其为中心的规则二维虚拟相机网格。
- **虚拟视角数量**：$25\times25=625$。
- **模型**：LaCT，前馈式新视角合成；输入多视角图像与相机条件，输出指定虚拟相机处的 RGB。
- **速度**：项目页报告单张 A100 GPU 下生成一个 $25\times25$ 光场用时不足 30 s；这不是扩散模型单张图像的推理时延。

> **LaCT 按用户要求简写**：只需知道它负责把有限视频视角扩展为规则密集的子孔径图像；这里不展开 TTT、Fast Weights、Window Attention、内部网络公式。

### 3.2 为什么不直接使用原始视频帧

手持视频相机通常沿非规则轨迹移动，而光场重聚焦需要在一个虚拟孔径平面上对视角进行规则采样。故先通过 LaCT 补全虚拟相机网格，再沿网格积分。

### 3.3 虚拟相机基线

- **基线过小**：不同视角几乎相同，积分难以产生明显的景深差异。
- **基线过大**：新视角偏离训练观察范围，合成误差、遮挡错误可能增多。
- **论文思路**：使用光流/视差相关统计做自适应基线校准，使不同场景的子视角位移尺度处于适合重聚焦的范围。
- **证据边界**：尚无官方完整数据生成源码可用于逐项核实这一模块的阈值和实现参数，故不虚构具体算法超参数。

### 3.4 光场的数据结构

四维光场可以记为：

$$L(x,y,u,v)$$

| 维度 | 含义 |
|---|---|
| $x,y$ | 子孔径图像内的空间像素位置 |
| $u,v$ | 子孔径相机的二维位置/视角索引 |

固定 $(u,v)$，就得到一张 RGB 子视角：

$$I_{u,v}(x,y)=L(x,y,u,v).$$

对于 $25\times25$ 阵列，一种方便的索引为 $u,v\in\{-12,\ldots,12\}$。这是**中心化索引示意**，不等于有标定意义的真实孔径坐标；实际物理或虚拟距离取决于相机基线设置。

## 4. 最关键的物理机制：光场重聚焦与孔径积分

### 4.1 为什么平移不同子视角能改变对焦

在校正后的小基线近似下，同一物体点随子视角 $u$ 的水平位置可写为：

$$x(u)=x_0+pu,$$

其中 $p$ 为该物体点的视差斜率。不同深度通常具有不同的 $p$。

为了对焦到视差斜率 $\kappa$ 对应的平面，在每个子视角中执行与 $u$ 成比例的平移：

$$I_u^{(\kappa)}(x)=I_u(x+\kappa u).$$

于是该物体点的对齐残差：

$$\Delta x=(p-\kappa)u.$$

**当 $p=\kappa$：** 所有视角中的点对齐，积分后仍然集中，表现为清晰。  
**当 $p\ne\kappa$：** 不同视角中的点位置不一致，积分后分散，形成离焦模糊。

> 【公式解释】这一维模型用于说明 Shear-and-Sum 原理。$\kappa$ 本质上是与子视角视差对齐有关的重聚焦参数，不可不加标定地直接解释为米制对焦距离。

### 4.2 规则光场的二维离散积分

可以将连续积分离散化为：

$$
I_{\kappa,a}(x,y)=
\frac{1}{|\mathcal A(a)|}
\sum_{(u,v)\in\mathcal A(a)}
L(x+\kappa u,\ y+\kappa v,\ u,v),
$$

其中：

- $\kappa$：对焦平面/视差对齐参数。
- $a$：虚拟光圈半径。
- $\mathcal A(a)$：位于选定虚拟孔径范围内的子视角集合。
- $|\mathcal A(a)|$：参与积分的子视角数量（归一化）。

若采用圆形光圈采样，则可表示为：

$$\mathcal A(a)=\{(u,v)\mid u^2+v^2\le a^2\}.$$

实际插值、边界补偿与坐标标定由具体实现决定；上式是便于复现理解的离散表达。

### 4.3 为什么扩大光圈会增大散焦

对一个局部视差斜率为 $p$ 的点，其重聚焦后二维位移近似：

$$
(\Delta x,\Delta y)=((p-\kappa)u,(p-\kappa)v).
$$

对圆形孔径 $u^2+v^2\le a^2$，最大空间偏移尺度满足：

$$\boxed{R_{\rm blur}\propto a|p-\kappa|}.$$

因此：

- 改变 **$\kappa$**：换一个深度/视差平面保持清晰。
- 增大 **$a$**：让其他深度的投影位置分散得更广，散焦增强。
- 缩小 **$a$**：散焦减弱；接近中心视角时趋向针孔式全清晰结果。

### 4.4 为什么它能处理部分复杂可见性

光场每个子视角包含视角相关可见性，例如网格间隙看到的背景、镜面反射随视角变化的内容。积分并不强迫每个输出像素先由**单个预测深度**决定 CoC。因此有机会降低深度崩塌造成的背景泄漏、边界光晕和反射错误。

**边界**：这是对多视角表示能力的解释，不是说光场重建天然精确。若 LaCT 子视角本身有一致性错误，积分也会继承错误；非一致的小范围错误可能被平均减弱，但不能保证所有伪影都消失。

## 5. 由光场动态生成扩散训练图像对

### 5.1 一份光场，多种光学条件

记光场渲染函数为：

$$\mathcal R(L;\kappa,a).$$

每次训练从同一光场选取两套参数：

$$(\kappa_1,a_1),\qquad (\kappa_2,a_2).$$

生成：

$$I_{\mathrm{in}}=\mathcal R(L;\kappa_1,a_1),$$

$$I_{\mathrm{gt}}=\mathcal R(L;\kappa_2,a_2).$$

控制条件：

$$\boxed{\Delta\kappa=\kappa_2-\kappa_1,\qquad \Delta a=a_2-a_1.}$$

所以一个训练样本可以记为：

$$(I_{\rm in},\Delta\kappa,\Delta a,I_{\rm gt}).$$

注意：**$I_{\rm gt}$ 是在指定目标光学状态下、由光场积分生成的配对监督图，不是所谓的全清晰 GT 的固定版本。** 输入和目标都可以处于不同程度散焦状态。

### 5.2 双向编辑来自有正有负的参数差值

| 条件变化 | 学习目标 |
|---|---|
| $\Delta\kappa\ne0$ | 移动对焦平面，可从近到远或从远到近 |
| $\Delta a>0$ | 增大有效孔径，通常增强离焦 |
| $\Delta a<0$ | 减小有效孔径，减弱离焦，可能恢复部分清晰纹理 |
| $\Delta\kappa\ne0,\Delta a\ne0$ | 联合改变对焦位置和散焦强度 |

数据生成阶段采用光场积分；最终编辑器通过生成式模型学习这种变换，**不是推理时精确执行同一个光场积分算法**。

## 6. 扩散编辑模型（只保留必要结构与重点）

### 6.1 网络输入输出和整体结构

- 基础模型：SDXL 风格的潜空间扩散编辑器。
- 源图像 $I_{\rm in}$ → VAE Encoder → $z_s$。
- 目标 GT $I_{\rm gt}$ → VAE Encoder → $z_0$，再随机加噪成 $z_t$。
- $[z_t,z_s]$ 沿**通道维**拼接，送入 U-Net（源图提供空间内容条件）。
- $(\Delta\kappa,\Delta a)$ 经 Fourier Features + MLP，作为光学编辑条件注入 U-Net 的 Cross-Attention 相关模块。
- U-Net 执行条件去噪；推理末尾 VAE Decoder 输出 RGB。

### 6.2 两个标量究竟怎样注入

作者不是将 $(\Delta\kappa,\Delta a)$ 直接替换为 CoC Map，而是先将连续标量编码成高维特征。

一种通用 Fourier 特征写法：

$$
\gamma(x)=[\sin(2^0\pi x),\cos(2^0\pi x),\ldots,\sin(2^K\pi x),\cos(2^K\pi x)] .
$$

然后：

$$\mathbf c=\operatorname{MLP}([\gamma(\Delta\kappa),\gamma(\Delta a)]) .$$

$\mathbf c$ 注入去噪网络条件通路。**上式是通用特征展开示意**；具体频率数、MLP 层数、cross-attention token 组织形式不能在未看到源码前自行补齐。

| 输入 | 进入哪一部分 | 负责什么 |
|---|---|---|
| $z_s$ | 源图潜变量，和带噪目标潜变量通道拼接 | 保留场景布局、语义与图像结构 |
| $\Delta\kappa$ | Fourier → MLP → 条件网络 | 控制焦点位移方向/幅度 |
| $\Delta a$ | Fourier → MLP → 条件网络 | 控制光圈改变方向/幅度 |
| 时间步 $t$ | 扩散时间条件 | 指定噪声水平 |

### 6.3 GT 怎样参与扩散损失

**关键顺序是先编码目标 GT，再加噪，再训练恢复目标分布。** 不是先生成最终 RGB 再只计算一次 $L_1(I_{\rm out},I_{\rm gt})$。

用标准 $\epsilon$-prediction 扩散形式举例：

$$z_0=E_{\rm VAE}(I_{\rm gt}),$$

$$\epsilon\sim\mathcal N(0,I),\qquad t\sim\mathcal U(\{1,\ldots,T\}),$$

$$\boxed{z_t=\sqrt{\bar\alpha_t}z_0+\sqrt{1-\bar\alpha_t}\epsilon},$$

$$\boxed{
\mathcal L_{\rm diffusion}
=\mathbb E_{t,\epsilon}\Big[\|\epsilon-\epsilon_\theta(z_t,z_s,t,\mathbf c)\|_2^2\Big].
}$$

> **重要准确性说明**：这里的加噪与 $\epsilon$-prediction 目标是通用教学表达。它说明成对 GT 如何在扩散训练中起作用；**未核实到官方完整训练代码和论文中噪声/速度参数化的精确配置**，不能据此断言作者必然采用此精确形式、损失权重或调度器。若复现，需以原文和实际脚本确认 $\epsilon$、$v$-prediction 或其他目标。

### 6.4 推理流程

$$
I_{\rm in},\Delta\kappa,\Delta a
\rightarrow z_s,\mathbf c
\rightarrow \text{条件去噪采样}
\rightarrow \hat z_0
\rightarrow D_{\rm VAE}(\hat z_0).
$$

- 无需原始视频或 LaCT。
- 无需在线恢复 $25\times25$ 光场。
- 无需在线预测单目深度。
- 输出是单帧图像；没有额外的跨帧一致性监督机制被证明。

## 7. 数据集、评价任务与指标

### 7.1 Vid2Bokeh Dataset

- 上游数据：**DL3DV-10K** 普通视频。
- 项目报告：约 **10K** 段视频 → **100K+** 密集光场样本。
- 单个光场：$25\times25$ 个子孔径视角。
- 光学条件：连续的 $\kappa$ 与 $a$；训练图像对由同一光场在两套参数下动态生成。
- **注意区分**：100K+ 是**光场/样本量**，不代表 100K 个互不相同的原始视频，也不代表公开了 100K 组现成可下载 GT 图片。

### 7.2 评测层次

| 层次 | 评测对象 | 参考/比较方式 |
|---|---|---|
| Blender 数据保真度 | 生成的光场积分图 | 物理路径追踪散焦 GT；理想光场积分 GT |
| 双向 Refocusing | 最终扩散编辑器 | 前景→背景与背景→前景的配对测试 |
| 光圈控制 | 最终扩散编辑器 | 多档光圈的目标散焦图 |
| 真实样例 | 复杂真实场景 | 定性对比：反射、透明、细线遮挡等 |

常用指标：PSNR↑、SSIM↑、MS-SSIM↑、LPIPS↓、DISTS↓。具体表格只呈现所在实验实际使用的指标。

### 8.4 定性现象与“消融”边界

- 镜面/水面反射：单目深度容易把镜中虚像压到镜面深度；光场可利用视角相关的反射变化。
- 透明物体与网格：不同子视角的可见背景层次有助于减轻单层深度引起的边界错误。
- 孔径积分可以减弱部分**各视角互不一致**的新视角合成伪影，但不能修正一致性系统偏差。
- **警惕分类错误**：多档光圈渲染对比是一个**基线比较表**，并不等于针对“删除某个模块”的严格消融实验；当前尚未逐项核实官方完整消融表，所以不捏造 LaCT、光圈基线、条件编码等模块的具体增益数字。

## 9. 方法限制与适用边界【官方项目】

| 项目 | 局限 |
|---|---|
| 最终模型分辨率 | 项目页报告在 **768×768** 进行编辑；高分辨率双向编辑仍待拓展 |
| 光学高光 | 使用 RGB/sRGB 而非 RAW 线性高动态范围传感器数据，亮点散焦的物理表现近似 |
| 数据场景 | 光场构建主要假设场景近似静态；独立运动物体可能破坏一致性 |
| 相机信息 | 依赖估计位姿和新视角合成，位姿错误会影响光场质量 |
| 光圈模型 | 默认圆形孔径；其他形状需改变孔径积分区域 |
| 推理输出 | 单图像编辑，不保证连续视频帧之间时间一致 |
| 去模糊真实性 | 去除严重散焦时可能生成合理但非真实的纹理细节 |

**重要区分**：论文强调的是训练标签具有更可信的几何关系，并且最终单图编辑在复杂几何处取得更好结果；这**不是**“推理时重建显式三维场景”，也**不是**“每张输出都具有严格物理一致性”的证明。

## 11. 参数与公式速查

| 记号 | 含义 | 在什么阶段使用 |
|---|---|---|
| $L(x,y,u,v)$ | 四维光场 | 数据生成 |
| $25\times25$ | 每份光场的子孔径视角网格 | 数据生成 |
| $\kappa$ | 对焦/视差平面对齐参数 | 光场重聚焦、编辑条件 |
| $a$ | 虚拟孔径半径 | 光场积分、编辑条件 |
| $\Delta\kappa$ | 目标与输入的对焦参数偏移 | 扩散条件 |
| $\Delta a$ | 目标与输入的光圈参数偏移 | 扩散条件 |
| $I_{\rm in}$ | 源光学设置下的输入 RGB | 编辑网络源图 |
| $I_{\rm gt}$ | 目标光学设置下的积分 GT RGB | 扩散训练监督 |
| $z_s$ | 源图 VAE 潜变量 | U-Net 条件输入 |
| $z_0$ | 目标 GT VAE 潜变量 | 扩散训练加噪前 |
| $z_t$ | 带噪目标潜变量 | U-Net 去噪状态 |
| $\mathbf c$ | 光学偏移编码（Fourier+MLP） | U-Net 条件模块 |

**最重要的两个关系：**

$$\boxed{I_{\kappa,a}=\operatorname{ShiftAndSum}(L;\kappa,a)}$$

$$\boxed{\operatorname{Editor}(I_{\rm in},\Delta\kappa,\Delta a)\rightarrow I_{\rm out}}$$

**前者是数据合成阶段的光学计算；后者是单图像条件生成模型。二者不能混为一谈。**

## 12. 值得保留的科学问题（读论文时的疑问，不是作者已解决的结论）

1. **子视角一致性**：LaCT 对反射/透明材料的角度变化究竟有多准确？角度积分能够消除哪些随机伪影，哪些会系统残留？
2. **可观察性限制**：从原来严重模糊的单张图恢复远处清晰纹理时，输出有多少是正确重建，多少是生成式补全？
3. **光学标定**：$\kappa,a$ 是数据集的虚拟光学控制坐标；能否映射到真实相机焦距、f-number、CoC 的物理单位，需要额外校准。
4. **时序一致性**：逐帧对视频运行单图扩散编辑器，不等于得到跨帧稳定的景深视频。
5. **公平基准**：若未来官方数据与权重公开，可将数据生成保真度、单帧编辑质量、时间一致性和推理速度分开评测，不应混合为一个指标。
