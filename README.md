# OPPO Depth-Guided Video Bokeh

面向云侧离线精修的视频虚化研究与公开方法复现。

2026-11-02 起转向 **动态 3DGS + 光学虚化** 路线。2026-11-09 形成整体方案草案（前馈多帧动态高斯 + 可微光圈渲染，见 `02_方案设计/路线三_前馈动态高斯光学虚化_整体方案与前期准备.md`），P1–P7 前期准备已完成，当前处于 **C1 前提验证**阶段，尚未训练、方法仍为候选。此前以 **Any-to-Bokeh** 为核心视频 baseline 完成的 Synthetic 七方法、DAVIS 六方法、效率评价与失败分析保留为对比基础和动机证据；V2 隐式几何、Student 几何修正等方向已暂停，相关方案归档于 `02_方案设计/归档路线/`。

课题原文中的低帧率粗深度输入、深度时空补全、多头联合预测等仍作为历史提案和候选扩展保留，但不再作为当前必须实现的核心创新或 Ours 前置条件。当前有效研究方向、执行顺序和冻结结果以中央进度文档为准。
