# Depth-Guided Video Bokeh

低帧率深度引导的端到端视频虚化统一框架研究。

本课题面向云侧视频虚化渲染，以高帧率 RGB 视频与低帧率粗糙深度为输入，探索深度补全、精细抠图与可控虚化渲染的联合建模，并关注时序一致性与处理效率。

## 当前状态

仓库目前收录课题提报材料与参考论文，尚未包含算法实现或实验代码。
